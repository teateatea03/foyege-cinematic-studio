# 2026-11-09：KakuDrop 案例轉為本機工作卡

使用者要求把已分析影片中可用的方法整合進技能。本次沿用 [T23](../skills/foyege-cinematic-direction/references/tutorials.md#t23-多視角表演與-ai-轉譯案例) 的貼文與取樣證據，沒有重新生成或重跑影片分析。作者自述、實際畫面與本技能延伸分開；Foyege 原始來源及主線不變。

## 採用與不確定範圍

| 本次採用 | 實際規則 |
| --- | --- |
| 表演與機位分軌 | 記錄角色世界目標；機位環繞不自動改成看鏡頭 |
| 捕捉範圍 | 臉、手、身體、接觸及視角各自記錄；新增或未拍部位另驗 |

| 本機路由 | 優先合格驅動與既有工作流；幾何問題再用 Blender，不新增平台依賴 |

沒有原始捕捉、4DGS 工程、生成前後對照或原提示詞。十五相機、演算法、模型版本皆不成為本機能力保證或必要部署。展示片的大表情與快運鏡只當風格選項，不替代克制表演的處理停頓、壓制與殘留。4DGS、骨架／臉部動捕與影片驅動分流，沒有把 MoCap 寫成不能處理臉。

## 原創文字走查

以下是維護者依新卡完成的文字輸出，非獨立模型評測或影片驗收。

### 1. 上半身捕捉，全身成片

輸入：參考只拍到胸口以上，成片生成盤腿與鞋；要求整個身體標「捕捉已驗證」。

輸出：臉／上身可見區間按實際檢查記錄，下半身標生成補全或來源未知，另驗腿腳、接地與接觸。沒有原始資料時，不替臉部標無損保留。

### 2. 環繞時仍看同一人

輸入：C1 原本看向世界位置固定的 C2，攝影機繞背；要求沒有刺激也自動追鏡。

輸出：維持 C2 為目標，機位與角色轉向分開。若要改成對鏡互動，明確改表演設計。主要嘴角反應被背面遮掉時，先留在可見近景，之後才展示繞背。

### 3. 變速後的事件時間

輸入：未裁切的參考在 1 秒出現反應，整段以半速呈現；要求仍拿輸出的 1 秒比較。

輸出：該事件在此簡化時間映射下落到輸出 2 秒，按各自時間戳／fps 定位，不以相同影格號比對。實際若有裁切、非均勻變速或模型偏移，另按對應事件記錄，不假定理想映射即生成結果。

### 4. 沒有 4DGS、也沒有中間預演

輸入：只有單視角合格驅動和既有影片轉移工作流，要求先取得十五相機才能開始。

輸出：比較參考與最終輸出兩層，中間標未使用；先核對現有模型輸入及可行機位。缺背面資料時改近景／插鏡或補拍，不將單視角或無臉白模視為任意視角的精確臉部來源。

### 5. 參考與成片尾端不同

輸入：驅動片尾端微笑，但已接受生成片仍有皺眉，下一鏡要求直接承接驅動片的笑。

輸出：先確認皺眉是否符合本鏡意圖。若已接受它，下一鏡承接成片的皺眉；若必須以笑接續，先修正並重新接受本鏡，不由參考片覆蓋真實成片狀態。

### 6. 缺素材與範圍外

輸入 A：只要一個克制反應提示詞，沒有角色圖、驅動或音軌。
輸出 A：給事件順序與明確待綁定欄位，不索取完整三層資料、不啟動生成，也不宣稱精確時序通過。

輸入 B：只要啟動／關閉挖礦。
輸出 B：交由明確授權的程序操作，不使用導演卡；本次技能整合沒有啟動礦機或 GPU 實驗。

## 證據界線

前次案例分析已看全片 0.5 秒取樣與兩段 0.1 秒重點取樣；沒有連續順播、ASR 或聽音，外部 VLM 關閉。原影片及本機分析檔保留私人目錄，公開只提供來源、原創摘要和工作卡。本次沒有以新 GPU 渲染或模型推論驗證表演轉移效果，也未執行 provider 模型評分。現有對話可按需讀更新參考，新對話正常載入。
