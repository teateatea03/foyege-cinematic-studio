依使用者要求，本輪僅優化核心以外的製作支援。Foyege 主入口、微表演、話輪、空間、表演轉譯、核心作者來源、白模腳本及核心說明不改。本輪新增 [media-handoff.md](../skills/foyege-cinematic-direction/references/media-handoff.md)，由製作頁按需引入；六組第一方資料詳見 [T24–T29](../skills/foyege-cinematic-direction/references/tutorials.md#2026-11-09-製作周邊研究)。

## 採用的資料與處理

| 來源 | 改善的周邊流程 | 適用邊界 |
| --- | --- | --- |
| Adobe ingest／proxy | 原始媒體與工作副本分開、代理身份映射及回連確認 | 不要求 Premiere，不假定其他工具支援相同功能 |
| OpenTimelineIO adapters／feature matrix | 時間線交換先查格式及插件能力、以代表性段落比對 | 不承諾所有特效／變速完整往返，不安裝 OTIO |
| EBU R 128-2023 | 響度、真峰值與節目量測範圍；保留原主檔 | 廣播目標不套成所有 MV 的固定值 |
| Netflix 繁中指南 | 區分一般字幕、SDH、不同讀者及實際音軌版本 | 字數、字速與歌曲條款屬該平台，非所有創作標準 |
| W3C WAI | 自動字幕需校對，必要聲音與播放器呈現各自驗證 | 本次不宣稱完成 WCAG 符合性評估 |
| YouTube 上傳建議 | 母版與平台版分開，以具體交付 profile 核對 | 不猜未知色彩、不硬改畫幅或增加影格 |

新頁另提供兩條以既有 FFmpeg 工具執行的只讀量測命令，及最小交接單。沒有新增軟體、雲端服務、模型、權重或正式專案設定。只要單鏡提示詞／劇本時不展開整套周邊表單。

## 原創文字走查

以下是維護者對新參考的手動文字走查，沒有獨立模型評分。

### 1. 代理檔誤作母版來源

輸入：兩個 take 都叫 final，剪輯已連到低解析度代理，要求直接宣稱母版完成。

輸出：先按 take／版本與原檔映射確認接受狀態，連回正確高品質來源再檢查輸出。保留代理與舊檔，不依名稱挑選或刪除。未重新連結／檢查時標待驗。

### 2. 時間線交換遺失效果

輸入：從一個剪輯器匯出 EDL，要求複雜變速、巢狀與全部特效自動完整保留。

輸出：核對實際格式／adapter，先往返代表性片段，對審片參考的切點、長度與聲畫；不能傳遞的效果交設定或已確認烘焙片，保留原始工程。沒有實際測試就不宣稱相容。

### 3. 網路 MV 自動改響度

輸入：未指定交付平台，要求把鎖定歌曲主檔改成 −23 LUFS，因為「EBU 是標準」。

輸出：保留主檔，先記實際量測和交付用途。廣播規範不自動成為該 MV 的目標；若之後指定平台／接收者，按其規格另產交付版。量測通過不代表演唱內容、接縫或同步已聽審。

### 4. 繁中字幕與歌詞

輸入：只有自動轉寫，要求所有影片固定每行 16 字／每秒 9 字，並把句級歌詞當作已完成逐字變色。

輸出：先辨一般字幕、SDH 或歌詞交付，Netflix 數字僅作相應規範參考。核對否定詞、數字、專名與音軌版本；逐字效果另綁音節時間，沒有音檔／播放器檢查就保留未檢查。

### 5. 變動幀率與未知色彩

輸入：只有平均 fps，要求所有來源補到 60fps、直接標 BT.709，並宣稱不會不同步。

輸出：先保留原生時間資訊與已知標記，需要時查幀時間戳，按實際剪輯／交付做有紀錄的轉換；未知色彩保留未知。不把補幀、變速、重採樣混稱為無損封裝。

### 6. 檢測值與範圍邊界

輸入 A：自動黑格檢測命中片尾的刻意黑場，音訊可解碼，要求判定全片失敗或已完整驗收。
輸出 A：先對設計判定黑場是否有意；結構、內容、同步及聽審各自記錄，沒有完整播放不寫全片通過。

輸入 B：只要一句模型動作提示詞。
輸出 B：沿既有導演入口交付，不強制代理、混音、字幕或母版表單。

## 本機命令檢查

實查已安裝 ffprobe 的 JSON／streams／format 選項與 ffmpeg ebur128 的 true peak 選項。以先前合法取得的約 11.7 秒公開案例素材，執行結構探測及第一音軌的全片響度掃描，兩者 exit 0、JSON 可解析；前後 SHA-256 一致，沒有改動來源或正式 MV。

本機 FFmpeg 為 8.0.1。此片儀表回報 I −70.0 LUFS、Peak −inf，沒有可用來校準非靜音節目的響度證據；這次只確認命令、解碼與 JSON 入口可用，不主張非靜音量測準確度。

這只是命令與結構的 smoke check；沒有新增混音、字幕渲染、剪輯器往返、GPU 渲染、模型生成、ASR 或人類聽審。沒有把量測結果當作內容驗收，也沒有啟動挖礦。
