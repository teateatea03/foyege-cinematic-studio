# Foyege24 方法的核心交付

Foyege24 的公開白模教學是本專案的主線。[來源 S4](../skills/foyege-cinematic-direction/references/sources.md#s4-blender-白模完整流程)

| 層 | 要決定的事 | 執行依據 | 檢查 |
| --- | --- | --- | --- |
| 人物目的 | 想讓對方相信什麼，何處有壓力 | 劇本與人物關係 | 刺激是否可追溯 |
| 空間 | 角色、家具、機位、路徑與縱深 | 地圖或白模 | 世界座標、遮擋、軸側 |
| 外觀 | 角色、服裝、道具與場景質感 | 各自參考圖 | 身份與參考責任 |
| 微表演 | 目光、嘴角、下巴、呼吸的先後 | 文字、參考表演或可用 rig | 原速可讀，再逐幀定位 |
| 物理動作 | 發力、接觸、反作用與恢復 | 預演和可見因果鏈 | 支撐、接觸及持有者 |
| 接鏡 | 前鏡終態、後鏡起態與聲音 | 已接受 take 及世界狀態 | 同機位續接與反打分別設計 |

## 眼神與微表情

先給具名視線目標，再決定哪些部位先改變、哪些保持。設計眼先頭後時要有眼睛已轉向而頭仍未跟隨的可讀中間狀態。時間窗是導演目標，逐幀可辨的延遲與觀眾原速可讀性各自驗收。

克制反應可以安排局部洩漏、嘗試維持、控制未完全恢復及尾端殘留。依角色與當前鏡頭挑選事件。嘴角、眼瞼、視線、頭頸與呼吸分開檢查，讓主要變化有足夠注意力與停留。

若指定持續注視，執行稿用眼瞼開度、唯一目標與保持條件描述。既有試片曾在疲態描述下閉眼，改為明確開眼條件後，在單案例維持開眼淺笑。[歷史短測](../skills/foyege-cinematic-direction/references/local-tests.md)

對話將台詞中的詞與表情變化綁定，交代當下話語權、誰準備接話，以及打斷或沉默後聽者仍在做什麼。用「目的、觸發、可見變化、保持／禁止反應」檢查節拍；聲音、局部表情與切後殘留分開驗收。已鎖定的 MV 保留原詞與唱法。見新增的 [詞級觸發與話輪](../skills/foyege-cinematic-direction/references/acting-beats.md) 及 [影片依據 Y1–Y2](../skills/foyege-cinematic-direction/references/sources.md#2026-11-08-youtube-補充)。

補充教材另把參考表演的選取、角色轉譯、發音中的表情承接與反應素材的場景用途具體化；這些是本專案整合，不新增作者原始方法主張。見 [表演參考與剪接選擇](../skills/foyege-cinematic-direction/references/performance-transfer.md)。

## 空間與接鏡

同一世界地圖可支援多機位，每鏡重新推導畫面左右。反打使用前鏡已接受的世界與表演狀態重建新構圖。上一鏡尾幀可作狀態參考，首幀輸入則需符合新鏡機位。

對話與歌唱時，口部動作依音軌安排，聆聽、目光與非口部殘留可承擔情緒。聲音刺激與反應的先後需要時間線或實際聲畫驗證。

從場景到鏡頭時，另查觀眾與人物各在哪一點取得資訊，必要選擇／動作／反應由哪個可用區間承擔。同框微反應安排主要讀點，補鏡保留能比對的動作重疊。沿用空間、外觀、表演分工，見 [場景到鏡頭覆蓋](../skills/foyege-cinematic-direction/references/scene-coverage.md)。

## 最小工作卡

```text
鏡頭目的與角色當下目的
角色／場景／道具／預演素材責任
起始站位、視線、持物與表情
刺激 → 一次主要變化 → 恢復／殘留 → 終態
可見景別、焦點、光線與遮擋
實際模型可接收的控制訊號
前鏡承接來源與下一鏡責任
通過／需修正／未檢查及具體時間點
```

創作卡、執行提示詞與實際已接受輸出各自保存。完整表格與原創例見主技能參考檔。
