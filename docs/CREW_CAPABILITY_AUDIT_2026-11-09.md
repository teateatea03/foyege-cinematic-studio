# 2026-11-09 劇組職能與技能缺口盤點

結論：已有導演、編劇、製作協調、場景、音樂與後期規劃，主要缺口是部門交接的具體程度及專項能力驗證。本輪新增兩份共用參考並接回現有入口；沒有宣稱一套文字技能已取代完整實體劇組。

職稱及分工會隨國家、規模和媒材改變。以下按 22 組常見職能整理，並非要求每次雇用 22 個部門；一人可兼任，交付責任仍須明確。職能背景見 [T38–T44](../skills/foyege-cinematic-direction/references/tutorials.md#2026-11-09-劇組職能研究)，能力分類是維護者對當前檔案的評估。

## 本次檢查範圍

- 公開 Foyege 入口及空間、運鏡、表演轉譯、素材交接、專案維護等相關參考。
- 公開 cinematic-screenwriting 入口與既有導演交接。
- 本機 film-production 入口及 production-design、shot-card、dialogue-production、post-and-delivery、testing-and-review、sources。
- 本機 set-design、music-designer、editing-pipeline 的入口；沒有因此執行這些技能的建模、音訊或圖像流程。

film-production 等本機配套不在本公開包內，也不是使用公開 Foyege 的必要依賴；新參考可獨立使用。本次沒有審計所有已裝技能或每個工具執行環境。特別核對 editing-pipeline：它處理單張圖像編輯，不當成影片剪輯功能的證據。

「已有規劃」表示文件提供方法，不表示已經實作／驗收整部作品；「需補交接」不表示整個部門原先完全不存在；「專項待驗」不能靠新增表單改成已通過。

## 優先補強

本輪實際補六項交接細節，均透過兩份按需參考完成：

1. 製片／副導：從本次交付反查前置依賴、負責人、接受者及資源順序。
2. 美術／服化／道具：同故事日狀態、重拍重置與敘事續拍分開。
3. 攝影／燈光／調色：光源母本、可見讀點、已知色彩與顯示／烘焙處理。
4. 聲音：來源與 cue、觸發、同步、空間、補錄及聽審責任。
5. VFX：前期所需元素、source／timeline 範圍、相機、遮擋、mask／alpha 與回交。
6. 後期統籌：返回版本、定剪後變動、受影響下游與重查接點。

只補方法與路由，沒有新增模型、付費平台、帳號、常駐服務或強制全流程。film-production 本機入口與 production-design 加可選連結，既有階段、責任、版本及 GPU 規則保持。公開包維持兩個技能。

## 原創文字走查

以下是維護者對規則與交接的文字審查，不是實際模型行為測試或影片品質分數。

| 情境輸入 | 本次交付選擇與檢查 |
| --- | --- |
| 一句固定近景提示詞 | 直接交提示詞及待綁素材，不要求 22 部門、預算或啟動服務 |
| A 鏡角色／場景齊備，B 缺聲音 | 只標 B 的聲音依賴；A 與獨立文字工作照原授權繼續，不全專案停擺 |
| 同場反打要求「每鏡左側窗光」 | 先鎖世界窗位，再推導畫面方向；不能光源隨相機搬動 |
| 重拍前一 take 已把杯子喝空 | 回到鏡頭指定入鏡液面；敘事續拍才承接已接受尾態，不用 seed 假稱重置 |
| 生成一鏡只成功解碼、臉／手未看 | 技術成功與內容未檢查並列，不能升成已接受 |
| MV 已鎖母帶但無 stems | 保留母帶，缺分軌明記；音效用獨立 cue，不重生成或假造歌唱分軌 |
| VFX 要 alpha、只收到壓平 MP4 | 記資料缺口，評估可用分割／重取或改合成方案；不假稱已分層 |
| 定剪後鏡頭加長八格 | 回查對白／音樂／字幕／VFX 範圍及後段同步；不重跑無關 take |
| 5080 已有重工作、3080 Ti 忙 | 5080 工作待排，做獨立準備；另一卡負載不作否決，且不啟停礦機 |
| 表格要求精確演員空檔、GPU 費率，資料未給 | 分開記已知與假設，沒有偽造通告／金額；付費執行才依當次額度 |
| 數位特技預演成功便說現場可拍 | 保留數位幾何證據；實拍設備、執行者與專項條件仍由實際責任人處理 |
| 未安裝 film-production 的公開使用者 | 新頁自含交接卡，沿用自己的表單；不因可選配套缺少而停止提供導演設計 |

上述走查均符合新頁的預期分流，仍未測實際視聽媒體、模型判讀或完整製作吞吐。沒有生成、渲染、音訊處理或新增實拍。

## 剩餘驗證工作

方法頁增加不會自動完成專項。後續按作品最高風險選驗證：角色／聲線適配、必要視角與服裝材質、可控光色／焦點、VFX 實際返回、聲音與口型、時間線往返及完整成片。每次只補當鏡缺口，不為追求「全劇組」而無限制下載或一次測遍所有模型。

修改與檢查結果見 [VALIDATION](VALIDATION.md#2026-11-09-劇組職能補強)。新參考在本機與公開版一致，可由現有對話按需讀取；不需重啟生成服務。職能分類／文件保留檢查不等同最終製作已完成。
