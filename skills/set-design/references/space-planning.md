# 空間尺寸和光

排平面圖時查這份。數字是一般室內設計的常用值，故事需要時可以改，但要知道自己改了什麼。來源見 [sources.md](sources.md)。

## 擺放順序

1. 牆、門、窗。
2. 決定這個房間用途的大件：臥室的床、工作室的書桌、客廳的沙發。
3. 配合大件的東西：椅子、床頭櫃、茶几。
4. 放在家具上的東西：螢幕、檯燈、書。
5. 燈。
6. 機位。

大件通常靠牆。沙發和書桌的正面朝向房間的焦點，例如電視、窗或門。

## 人的尺寸

來源的數字是高個子男性（第 95 百分位），用來算「過不過得去」夠保守。角色比較矮時，眼睛高度和機位要跟著降低。

| 項目 | 尺寸 |
|---|---|
| 站姿身高 | 1.88 m |
| 站姿眼高 | 1.72 m |
| 肩寬 | 0.49 m |
| 椅面高 | 0.43–0.53 m |
| 坐姿眼高（離地） | 1.18 m |
| 膝下空間 | 至少 0.64 m |

估計：一般人站姿眼高約是身高的 93%。例如身高 1.55 m 的角色，站著眼睛約 1.45 m，坐在椅子上約 1.1 m。這兩個數字是推算的，沒有直接出處。

## 光

**分層。** 室內的光分四層：整體照明（吸頂燈）、工作照明（檯燈，約整體的 2 到 3 倍亮）、重點照明（照畫或物件，約 3 到 5 倍）、自然光（窗）。每個時段寫清楚哪幾層開著。

**照度參考（lux）：** 一般起居 150–300；閱讀和細部工作 300–500；臥室整體 50–150；走廊 50–100；視訊時臉上 300 以上而且要均勻。

**燈的色溫。** 來源建議的室內燈光色溫：早上 5000–6500 K、白天 4000–5000 K、傍晚 2700–3000 K、深夜 2200–2700 K。這是照明設計建議的燈光，不是天光本身。

**天光的顏色**（一般攝影常識，不是來自上面的來源）：日出日落時太陽偏橘紅，約 2000–3500 K；中午的太陽約 5000–5500 K；陰影裡被藍天照的地方偏藍，約 7000 K 以上。白模裡太陽用 `sun.kelvin`，天空用 `world_kelvin`。

**窗的方向決定一天的光。** 朝東的窗早上有直射光，傍晚沒有；朝西相反。先決定窗朝哪裡，再寫各時段的光。劇本裡寫「夕陽照進來」，就需要朝西或西南的窗。
