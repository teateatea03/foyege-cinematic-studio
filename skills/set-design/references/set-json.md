# set.json 格式和檢查項目

一個場景一份 `set.json`。三支腳本都讀它，所以平面圖、白模和機位畫面一定對得上。範例見 [sample_room.json](../assets/sample_room.json)。

## 座標

- 單位是公尺。
- 房間內側的西南角是原點。X 是寬（往東），Y 是深（往北），Z 是高。
- 牆的名字：`S` 是 y=0 那面，`N` 是 y=depth，`W` 是 x=0，`E` 是 x=width。牆厚往房間外長，不吃室內空間。
- `yaw` 是家具正面朝哪裡，從上往下看逆時針算：0 朝 −Y（南），90 朝 +X（東），180 朝 +Y（北），270 朝 −X（西）。只能填 0、90、180、270。
- `north_deg`：平面圖上北方的方向，0 表示北在圖的上方（+Y），順時針為正。只影響平面圖上的指北針。
- 太陽方向用房間座標，不用羅盤：`azimuth` 是從房間看太陽的方向，0 在 +X（東牆那邊），90 在 +Y，逆時針算；`elevation` 是太陽離地平線的角度。

## 欄位

```json
{
  "id": "STUDIO_A",              // SET ID，英數字
  "version": "v0.1",
  "name_zh": "瞳的工作室",
  "north_deg": 0,
  "room": {"width": 4.0, "depth": 3.5, "height": 2.6, "wall": 0.12},
  "openings": [...],
  "items": [...],
  "actors": [...],
  "paths": [...],
  "cameras": [...],
  "lights": [...],
  "times": [...]
}
```

`id` 都要不重複，而且只用英數字和單一底線：Blender 用它當物件名稱，內建字型也只有英數字。雙底線保留給零件，例如 `desk__leg0`、`A1__head`。

### openings：門、窗、開口

| 欄位 | 意思 |
|---|---|
| `type` | `door`、`window` 或 `opening`（沒有門板的開口） |
| `wall` | 在哪面牆 |
| `offset` | 從牆的起點（S、N 從 x=0 起算；W、E 從 y=0 起算）到開口邊緣的距離 |
| `width`、`height` | 開口的寬和高 |
| `sill` | 窗台高度（窗戶預設 0.9） |
| `hinge` | 門軸在左或右，`left`／`right`，以人站在房間裡面向這扇門來看 |
| `swing` | `in` 往房間裡開，`out` 往外開 |
| `leaf` | 白模裡門板的狀態：`closed`（預設）、`open`（開 90 度）、`none` |

### items：家具和道具

| 欄位 | 意思 |
|---|---|
| `center` | 平面上的中心 [x, y] |
| `size` | [寬, 深, 高]，寬和深是家具自己的方向（正面那邊的寬度、從前到後的深度） |
| `yaw` | 正面朝向 |
| `base` | 底部離地高度，放在地上是 0 |
| `on` | 放在哪件家具上；`base` 要等於那件的頂面高度 |
| `front_clear` | 正面前方要空出幾公尺，例如書桌 0.9、衣櫃 0.75 |
| `allow_in_front` | 可以放在前方空間裡的東西，例如書桌前的椅子 |
| `shape` | `box`（預設，實心方塊）、`chair`（座面加椅背）、`table`（桌板加四隻腳，坐著的人腿才伸得進去）、`booth`（前面開口的殼加一扇有窗的門，人可以站進去，例如休眠倉、衣帽間、電話亭） |
| `seat` | `chair` 的座面高度，預設 0.46；`booth` 的墊高地板高度，預設 0 |
| `door` | 只有 `booth`：`closed`（預設，關上）、`open`（往外開 90 度）、`slide`（滑到門軸那側的外面）、`none` |
| `hinge` | 只有 `booth`：門軸或滑門在 `left` 還是 `right`，以人站在它正面、面向它來看 |

| `color` | 已確認材質的代理 [r, g, b]，0 到 1；未定時不填，統一用中性灰 (0.5, 0.5, 0.5)，不輪流分色 |
| `front_mark` | 白模在正面貼一塊深色板，看得出朝向；預設開 |

`booth` 的 `open` 門會往前開，前方至少留一扇門寬；`slide` 是門板轉向後停在側板外側的簡化終態，不是平移滑門的運動模擬，也不檢查沿途掃掠。各狀態要人工查看門板與鄰近家具、牆是否碰撞。門的開關在不同場次不一樣時，從同一母檔派生狀態檔，另列替身及機位變更。

### actors：人物替身

靜止的替身，用來看比例、視線和機位拍不拍得到人。動作和走位在預演裡做（見 [ai-handoff.md](ai-handoff.md)）。

| 欄位 | 意思 |
|---|---|
| `center` | 站或坐的位置 [x, y] |
| `yaw` | 面向，任何角度都可以 |
| `height` | 身高，預設 1.6 |
| `pose` | `stand`、`sit`，或 `slump`（坐著趴在桌上睡） |
| `seat` | 坐姿和趴桌時的座面高度，要和椅子的 `seat` 一樣 |
| `rest` | 趴桌時桌面的高度，預設 0.75 |
| `base` | 腳下的地板高度，預設 0；站在墊高的地方（例如 `booth` 的墊高地板）時填它 |
| `on` | 坐、趴或站在哪件家具上；站進 `booth` 時填那個 `booth` |

坐姿的頭頂約是座面加身高的 52%，眼睛約加 45%。這兩個比例是估計值，沒有直接出處。趴桌的身體、手臂和頭的位置也是估計，只用來看遮擋和比例。

### 可辨識家具白模（S05）

`ring_light`：三腳架、中柱、約 0.45 m 的圓環、環中手機；`bookcase`：開放櫃體、側板、頂底板、4 片內隔板及各層書塊；`potted_plant`：圓柱花盆加葉團。原 `center`、`size`、`base`、`yaw` 是保留的外部佔位，不因改細節搬動家具。`build_set.py` 渲染圓環／柱／葉團原生網格；平面碰撞與 `to_previs` 用零件包圍盒近似，圓環分段，不能用整個實心盒填住孔洞。實際機位射線仍檢查原生網格。手機機位靠鏡頭／夾具會保留毫米級近物 WARN，不能假裝沒有硬體。

### 地毯／薄地面覆蓋

`shape: floor_cover` 用於貼地地毯等薄覆蓋，`base` 必須是 0、厚度最多 0.02 m。它仍接受房間邊界與幾何檢查，但不當成堵塞走道／家具前方的實體，也不把椅子壓在地毯上判成家具碰撞。不得以此型別跳過書櫃、紙箱等真正障礙物；驗證會拒絕厚或浮起的覆蓋。白模與預演仍輸出相同尺寸的薄方塊，未測滑倒或絆腳風險。

### paths：走道

`points` 是折線的點，`width` 是需要的寬度。主要走道 0.9 以上，家具之間 0.6 以上。`ignore` 列出可以擦身而過的東西；`ignore_walls: true` 表示貼牆走沒關係。從門口出發的走道，第一個點要離牆至少半個走道寬，不然門框本身就會被算成擋路。

### cameras：機位

| 欄位 | 意思 |
|---|---|
| `location` | 機身位置 [x, y, z]；坐姿眼高約 1.1 到 1.2，站姿約 1.5 到 1.7，依角色身高調 |
| `look_at` | 看向哪一點 |
| `lens` | 焦距 mm，以 36 mm 寬的感光元件計；水平視角 = 2·atan(18 / lens) |
| `level` | `true` 時機身保持水平，用鏡頭位移把 `look_at` 放回畫面中線，垂直線不歪 |
| `must_see` | 這個機位一定要看得到的東西：家具、替身，或門窗的 id；也可以只指零件，例如替身的頭 `MASTER__head` |
| `actors` | 這個機位要放哪些替身；不填就全部放。同一個人在不同場站不同位置時，每個機位只放那一場的替身，不然替身會互相擋 |
| `wild_wall` | 拆掉哪面牆才放得下這個機位；生成時那面牆不能出現 |
| `times` | 這個機位只出哪些時段的畫面；不填就是全部。定場機位出全部，其他機位只出它那幾場的時段 |

主觀鏡頭（人物的眼睛）可以放在椅子上方或 `booth` 裡面，平面檢查會出 `camera_clearance` 的 WARN，寫明是主觀鏡頭就好。機位要放在替身的頭前面約 0.15 m，不然鏡頭會在替身的頭裡面。

`to_previs.py` 會沿用機位的 `actors` 篩選。foyege 預演目前只支援站姿 1.6 m 替身，不能保留坐姿、趴桌或此處 `level` 的鏡頭位移；輸出 `source.notes` 會記錄差異，不能把它當成完全相同的表演或構圖。

### lights 和 times：燈和時段

燈具本身另以 `items` 的幾何代理呈現時，可在該 item 填 `"light": "L_ceiling"`，以及 `"color_off": [0.08, 0.08, 0.08]`。指向的燈必須存在；開燈時段用原 `color`，關燈時段用 `color_off`。不填 `light` 的家具不隨時段改色。這只改善白模的開關辨識，並非發光材質。

燈：`type` 是 `area`、`point` 或 `spot`；`energy` 是瓦數（Blender 的單位）；`kelvin` 是色溫；`times` 列出哪些時段開著；`aim` 是 spot 或 area 燈對準的點。

時段：`sun` 有 `azimuth`、`elevation`、`energy`、`kelvin`，沒有 `sun` 就是沒有陽光；`world` 是天空亮度，`world_kelvin` 是天空色溫；`exposure` 是那個時段的曝光補償。

## plan_check.py 的檢查

| 檢查 | 什麼情況出現 | 等級 |
|---|---|---|
| `inside_room` | 家具超出房間 | FAIL |
| `under_ceiling` | 家具頂部高過天花板 | FAIL |
| `support` | `on` 指到不存在的東西是 FAIL；`base` 和下面那件的頂面差超過 2 cm 是 WARN | FAIL／WARN |
| `overlap` | 兩件地上的家具重疊超過 1 cm | FAIL |
| `front_clear` | 前方空間碰到牆，或被別的家具佔了 | FAIL |
| `door_swing` | 家具在門往內開的範圍內 | FAIL |
| `door_width` | 門寬小於 0.8 m | WARN |
| `window_blocked` | 比窗台高的家具擺在窗前 0.6 m 內 | WARN |
| `path_width` | 走道最窄處小於要求；還有 0.6 m 以上是 WARN，更窄是 FAIL | WARN／FAIL |
| `camera_inside` | 機位在房間外卻沒寫 `wild_wall` 是 FAIL；寫了是 WARN 提醒；機位在家具裡面是 FAIL（`booth` 只算殼，站在裡面可以） | FAIL／WARN |
| `camera_clearance` | 機位離家具不到 0.3 m | WARN |
| `camera_height` | 機位貼近地板或天花板 | WARN |
| `actor_inside` | 替身在牆裡或房間外 | FAIL |
| `actor_headroom` | 替身頭頂碰到天花板 | FAIL |
| `actor_support` | `on` 指到不存在的東西是 FAIL；坐姿的 `seat` 和椅子座面差超過 3 cm 是 WARN | FAIL／WARN |
| `actor_clearance` | 替身撞到家具（桌子和它坐的那件除外；`booth` 只算殼和高度重疊的零件） | FAIL |

平面檢查只看地板上的佔地。高度、視線和光線要靠 `build_set.py`，好不好看要靠人。

`plan_check.py` 出兩張圖：`plan.png` 只有房間、家具、走道和替身，給人看佈置；`plan_cameras.png` 再加上機位。1.8 m 以上的東西（吸頂燈、線槽、高處的鐘）只畫空框，不擋住地上的家具。
