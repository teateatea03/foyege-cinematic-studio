# 譜面與分軌工具

本技能是編曲與分析方法；不附歌曲生成模型、分軌器、音檔或 YuE2 執行環境。命令從 song-arrangement 技能目錄執行，輸入採自己有權使用的素材。

## score_stats.py

只需 Python 3.10+，命令為 `python scripts/score_stats.py 名稱=score.abc`。用 `% 段落名` 分段、`V: Vocal` / `V: Ins` 指定聲部；支援大／小調 K 欄位與 `[K:Gm]`、音名、升降記號、八度、時值、休止和小節。和弦文字從人聲行的引號內讀取。

這是 YuE2 案例的有限 ABC 方言統計器，不是完整 ABC 校驗器／合成器：忽略和弦堆疊、裝飾、歌詞欄，臨時升降按字母保持到小節結束（跨八度），不支援其他調式。通用 ABC 的語義可能不同；輸入其他方言先人工核對。生成器的可用和弦與接續能力要另外查實際版本。

## arc_compare.py

依賴 numpy、soundfile、librosa；建議使用獨立 Python 環境，不修改 ComfyUI 的套件。命令為 `python scripts/arc_compare.py 我的版本=stems:take1 參考曲=reference:ref1`。

每組需四個已分離且時間對齊的 stereo WAV：`take1_drums.wav`、`take1_bass.wav`、`take1_other.wav`、`take1_vocals.wav`。同組必須同取樣率、長度、起點與增益基準；腳本會裁成最短長度，不能用這個行為修正未對齊素材。讀取前先查 metadata，不要把 mono、空檔或不同取樣率直接送入。

分析採 8 秒窗並估計拍子、小節、和弦與人聲音高，需足夠長且有可辨鼓點／有聲人聲的音樂。短片段、自由節拍、靜音、人聲或鼓空軌可能失敗或產生無效值，遇到時停用該項指標，不能把例外或 NaN 解讀為音樂差。它不是任意音檔的品質評分器，也不執行分軌或自動找真實樂段。

## 案例與可重現範圍

F01–F08 是指定工具及素材下的歷史觀察。私人 ASR、說話人、換句、接縫及 YuE2 token 接續 runner 未隨包提供；不構成使用這兩支公開分析腳本的依賴，也不宣稱本包能重跑所有案例。

數字協助定位，不取代正常速度、合理音量下的實際聆聽。可解碼、ASR 高分或統計接近參考曲都不能單獨證明好聽或沒有接縫。
