# Foyege 導演方法與模型提示詞

與 film-production 的部門／階段規劃一起用。將既有 Foyege 研究轉為可操作的卡片與提示詞；原法、採用範圍與延伸分開記錄。[來源 F1–F5、S4、S6、S7](sources.md)

## 從意圖到可見反應

先寫人物當下目的、刺激與觀眾必須讀到的變化，再選少量可見事件。

    起始保持 → 刺激到達 → 一次主要變化
    → 接觸／局部反作用（需要時）→ 收回／恢復 → 殘留與尾端保持

眼神、嘴角、頭頸與呼吸各有用途，避免同時全部動。視線指向一個具名對象。需要眼先頭後時，寫清目光何時移、頭在何時保持、最後停在哪；不對所有角色套同一延遲。

先解決景別、遮擋、焦點與停留時間。看不到嘴角或接觸面的畫面不能靠形容詞當驗收證據。歌唱／說話時口部服從原音軌，把抿嘴、吞嚥安排在間隙，或改由眼神、手指承擔。

## 空間與參考責任

| 輸入 | 負責項目 | 不自動負責 |
|---|---|---|
| 身份／造型正本 | 五官、比例、LOOK、標誌 | 當鏡姿態與房間布局 |
| SET 參考 | 地理、家具、光源、材質 | 未畫出的空間 |
| 分鏡草圖 | 構圖、可見範圍、人物位置 | 最終材質、身份或精確運動 |
| 白模／驅動參考 | 相機、路徑、姿態及已實作時序 | 未實作的臉部表演或生成端必然服從 |
| 首／尾幀 | 當鏡起終視覺狀態 | 中間每一格的手部拓撲與因果 |
| 上一已接受 take | 切點狀態、情緒與道具殘留 | 換機位後仍相同的畫面左右 |

分開寫世界座標、畫面左右與角色自身左右。POV 確認誰擁有鏡頭、入鏡手及袖口。換機位時重算左右與眼線；直接用 A 尾幀當 B 首幀，只適用延續同一構圖且工作流支援的路線。

參考矛盾時，指定哪份管身份、哪份管布局。多個相機方案是候選，不是同一動作連做數次。

## 接觸與持有狀態

寫清「誰的哪個部位、沿哪條路徑、碰到哪個位置、對方如何反應、最後誰持有」。區分手指、手背與手腕；桌上不動的手不能突然變成抓握手。

預演精度按風險：站位可用代理形狀；抬腕、遮擋需可讀四肢；精確抓握需關鍵姿態與接觸區。白模通過只證明已實作的空間／運動部分，不證明生成的手或微表情通過。

## 導演卡編譯成執行提示詞

1. 固定卡片與素材版本，先查首圖是否已在動作之後、接觸是否被遮住。
2. 核對工作流真正支援的槽位：首尾圖、角色／場景參考、驅動片、音訊、負面提示、片長與畫幅。外部案例的功能不等於本機 H3 有同一入口。
3. 圖像已承擔的外觀只保留必要識別約束；文字集中在本鏡新增動作、機位、局部變化與終態。
4. 把太多同時事件拆成可讀時間窗。卡片保留精確格數目標，prompt 用該模型已驗證的語法；時間碼不是逐格控制保證。
5. 附對照：卡片欄位 → 素材／實際槽位 → 最終 prompt → 工作流版本。不能支援的要求列為待測或拆鏡／合成候選，不偷偷刪掉。
6. 保存完整送出文字與設定；只修被授權的層，留基準供比較。

Runway Gen-4 官方的簡潔、正向、聚焦動作指引，只適用該版模型。不要據此替 H3 規定字數、負面提示或多圖能力；H3 沿用當次已核對配方。

## 原創示例：勉強恢復營業笑

非歌唱反應鏡草案：收到畫外要求後，觀眾讀到她收回真實反應、再恢復服務姿態。身份、LOOK、SET、音軌與時長待綁定，尚非生成工單。

    固定近景。她看著畫外主人的眼睛，維持淡笑。
    指令結束後，仍看著主人，留出接收停頓。
    嘴角先鬆開，短暫吐氣，頭與肩保持穩定。
    嘴角恢復到更淡的弧度，眼瞼仍留前一拍的疲態。
    最後視線轉向鏡頭並停住；若需頭部跟隨，頭稍後小幅轉動。
    尾端保留可剪接的停留。

短測先選「嘴角收回與殘留」或「目光先移、頭稍後跟隨」一個最大風險。文字檢查不代表表演可讀，結果按 [測試與驗收](testing-and-review.md) 核對。

## 證據邊界

Foyege 既有研究中的白模教學與動作示例支持空間／文字分工、動詞因果及洩漏／壓制／殘留。本文的卡片欄位、MV 對位及測試方式是本機延伸。過往研究含全文閱讀、抽樣畫面與機器轉錄；未看的影片、無法精確定位的動作或模型能力不能補成已驗證。
