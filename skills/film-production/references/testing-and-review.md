# 測試、看片與返工

這是本技能的操作化檢查方法，來源與局部案例見 [來源](sources.md)。測試回答明確問題，候選數、重試與停止條件依當次工單，不因研究建議而自動擴量。

## 先選最高風險層

| 不確定性 | 最小可辨試驗 | 不能據此宣稱 |
|---|---|---|
| 身份／比例 | 同角色在必要視角、表情及光線下的比較 | 一張正臉好看就全角度通過 |
| 布局／機位 | 平面與起中終構圖、路徑及遮擋檢查 | 白模通過代表手指或表演通過 |
| 接觸／手別 | 一次抓握或交接，原生 fps 定位接觸區 | 尾幀對就中間拓撲對 |
| 微表演 | 一次刺激與一個主要反應，保留保持段 | 形容詞完整就觀眾讀得懂 |
| 聲畫／對嘴 | 固定音軌的一小段，原速看口部與聽聲音 | ASR 或波形正常代表情緒與同步自然 |
| 接鏡 | 相鄰片段的實際出入點，含聲音順播 | 靜態首尾相似就連續運動成立 |
| 完整段落 | 核心交流連同畫面、聲音、剪接做成小樣 | 單一易成功美景代表全片路線可用 |

先寫假設、通過條件、固定輸入／設定、允許變項、授權數量及停止方式，再生成。成本同時記載入／生成／檢查／人工修訂，不混成純 GPU 計算時間。

## 少步數／壓縮模型的試產

以 HyperFlow Flash 等新路線降低單次等待時，仍按「單人反應、雙人身份／接觸、雙人話輪」分層試產，沿用工單的候選上限。固定參考圖數與尺寸、輸出格數、載入／暖機條件，再比較步數或後端；分查嘴部、視線、切點及原生聲音，不用總耗時代替可用秒數。實際配方與 16GB 顯卡未測的範圍見 [Flash 適配](../../foyege-cinematic-direction/references/hyperflow-flash.md)。

## 看片順序與可見證據

1. 原速看敘事、動作及表演是否讀得懂，包含需要的聲音。
2. 逐格檢查風險時間窗：首次位移、接觸、閉指、受力反應、終態；保留實際格號／時間戳。
3. 分查身份、空間、拓撲、動作節拍、微表演、光與衣料；遮擋看不見記未檢查。
4. 與相鄰鏡頭順播，檢查方向、視線、速度、姿態、聲畫與情緒殘留。不要只看單張尾幀。
5. 依專案權限記接受或否決。技術成功不等於內容通過，也不能代替 Owner 的自然度判斷。

## 修在失敗的層

| 失敗 | 優先檢查／處理 | 修後再看 |
|---|---|---|
| 多出手、抓錯手、穿模 | 首尾姿態、手的歸屬、接觸路徑、遮擋；必要時改預演／拆鏡 | 全段手部拓撲及起終態 |
| 刺激先後相反 | 首圖已貼臉、路徑不足、事件指令矛盾 | 接觸／睜眼的實測順序 |
| 握得慢但形態正確 | 起算事件、動作有效區、距離與速度 | 原速可讀性、受力、接鏡及聲音 |
| 表情僵硬／忙亂 | 景別、刺激、主要反應、同時事件數 | 一次主要變化及殘留 |
| 衣料或道具消失 | 原狀態、支撐／遮擋、運動因果 | 物件去向及跨鏡狀態 |
| 膚色／曝光不合 | 色彩管理、光源與相鄰素材 | 匹配修正是否破壞身份／材質 |
| 全局小構圖跳動 | 可用餘量內的對齊或切點候選 | 臉、手、接觸區是否被裁掉 |
| 透視／幾何不相容 | 回到布局、機位或另取 take | 不用單一平移／縮放掩蓋三維錯誤 |

## 變速前先算，再驗

固定 fps、均勻變速下，動作的原始事件間隔為 n 格，目標為 m 格，所需速度約 n/m 倍。這只是時間換算，不保證表演自然，也不補出不存在的接觸。

例：30 格的握腕要壓到 6 格，約需 5 倍；最多 2 倍只能壓至約 15 格。不能寫「2 倍即可達標」。若六格包含從頭下抽手到閉指，不能改從碰腕開始計來湊數。

只在形態、接觸與因果正確的可用區段評估局部變速。保留原檔，記錄 source in/out、速度曲線、插值方式與輸出 fps。重新檢查丟格／插值、手與臉的形變、入出段加速度及聲畫；已對嘴段不能獨立變速後仍假稱同步。修不成時依原額度停止，交出具體未解原因或待批准的拆鏡方案。
