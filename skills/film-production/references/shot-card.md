# 鏡頭卡

一鏡一張；導演卡是正本，生成工單從卡片與已接受素材編譯。下列欄位可合併成精簡段落，不需要為無關項目造文件。空白與「未檢查」不可當成通過。

## 卡片欄位

| 欄位 | 必須說清的事 |
|---|---|
| ID／版本／狀態 | scene-shot-take；草稿、可測、已生成、技術／內容通過、Owner 接受、待重查 |
| 故事依據與目的 | 劇本／歌曲版本與段落；觀眾讀到什麼，人物當下想達成什麼 |
| 時間基準 | fps、畫幅、目標片長、從 0 或 1 起算；素材時間與歌曲時間分列 |
| SET／LOOK／道具 | IDs、版本、檔案、SHA-256、接受依據；每張參考負責哪一層 |
| 機位與可見範圍 | POV 擁有者、景別、角度、焦段感、構圖、運鏡、軸線、主光與遮擋 |
| 入鏡狀態 | 上一接受 take／實際切出格；位置、視線、手別、持物、接觸、衣物、情緒及聲音殘留 |
| 走位與動作節拍 | 世界／畫面／角色左右；誰從哪裡到哪裡；刺激、接觸、反作用、完成、保持各事件 |
| 微表演 | 目光、頭、嘴角、呼吸的先後；本鏡保持什麼、改變什麼、什麼在景別中可見 |
| 出鏡狀態 | 最終持有者、接觸點、姿態、光與道具狀態；下鏡如何承接 |
| 聲音路線 | 唱歌／對白／心聲／畫外音；母帶版本、同步點；原生生成音用或不用、後期補什麼 |
| 技術路線 | 實際工作流與支援槽位、首尾／驅動來源、尺寸、格數、設定、seed、嘗試數與停止條件 |
| 驗收 | 每一條可見效果、事件定義與容許範圍；身份／空間／動作／表演／聲畫各自結論 |
| 剪接／修復 | 有效範圍、前後餘量、可否局部變速、受保護的音軌／事件、插鏡用途與補拍條件 |
| 交接 | 本次可改的項目、不能動的正本、輸出位置、檢查者與未決依賴 |

## 事件表

先定事件的判斷方式，才有可重複的計時。固定 fps 的第 f 格，0 起算時間為 f/fps。N 格影片可播放 N/fps 秒，最後一格的時間戳是 (N-1)/fps，兩者用途不同。

| 事件 | 觀察定義 | 計畫格 | 實測格／證據 |
|---|---|---|---|
| 刺激 | 可見接觸，或指定音軌上的詞／音效 | 待定 | 未生成 |
| 動作開始 | 指定手／目光首次有意圖位移 | 待定 | 未生成 |
| 接觸 | 指尖或掌心在指定區域首次形成可辨接觸 | 待定 | 未生成 |
| 抓握完成 | 掌指形成環抱且對方手腕被穩定約束；不能只碰到 | 待定 | 未生成 |
| 反作用／終態 | 被握者的回應後回到可承接的穩定狀態 | 待定 | 未生成 |

「6 格內握住」先說明從抽手、手碰腕，還是臉被戳開始計。若採事件格差，f_closed-f_start<=6 在 24fps 為 <=0.25 秒；包含兩端的圖片張數不是同一計法。不得在看完後偷偷更換起算事件。模糊或遮擋看不清時標不可判，不用估計值冒充精確格。

## 範例：尾奏第二次戳的修訂草案

本例承接 T01 教訓，展示怎樣把缺口寫進卡片；不是 Owner 已接受的正式鏡頭，也不授權新增生成。

| 項目 | 草案 |
|---|---|
| ID／目的 | S12-040，主人其實也在裝睡，呼應冷開場 |
| 正本與狀態 | 劇本、SET-STUDIO、LOOK A、首尾圖與歌曲版本待綁定；DRAFT_ONLY |
| 畫面 | 瞳視點看向桌邊；她的女僕袖／白袖口可辨。主人頭不抬，近側手在頭下，桌上另一隻手保持原位 |
| 光與機位 | 依已接受 SET 的清晨主光及相機推導，不另發明房間；須看清指尖、臉頰局部與握腕區 |
| 入鏡 | 承接上一接受鏡頭的手指距離與主人姿態。T01 的貼臉起圖不可直接充當「尚有 3 公分距離」 |
| 動作 | 指尖接觸 → 局部臉頰受壓 → 頭下的手沿可行路徑抽出 → 掌心貼腕、四指與拇指環握 → 她的手短暫反應 → 穩定保持 |
| 速度目標 | 握住需迅速；「六格」的起算事件及手臂路徑待確認。若包括整個抽手，先預演距離與遮擋，不能改算成只計最後閉指就宣稱符合 |
| 毯子 | 肩部／手臂抽動導致布料滑落，餘下部分仍有去向與支撐；不瞬間消失 |
| 臉部限制 | 只露接觸必要局部是否符合「主人不露臉」需按劇本定義確認；未定前維持草稿 |
| 驗收 | 凹陷在接觸時可見；抓的是手腕且手別正確；無額外手或穿模；頭與桌上另一隻手保持；毯子因果連續；事件速度及原速自然度分別驗收 |
| 技術候選 | 可先評估既有 H3 首尾幀路線；1024×576／124 格／24fps／25 步只是 T01 基準，正式參數由當次工單綁定，不預先派抽數 |
| 聲音／剪接 | MV 保留鎖定歌曲母帶，原生音按本專案原政策不用。有效動作之外留接鏡餘量；變速與插鏡依下述條件評估 |

若手臂抽出太慢，先分清是整段路徑長，還是最後閉指拖延。縮短路徑、提前準備姿勢或拆鏡可能改變敘事／設計，先列方案，不能靜默更改已核定劇本。

臉頰凹陷插鏡若獲採用，要承接同一手別、方向、光、接觸區與時間；它是補足可見敘事資訊，不把原中景缺少的物理反應改標成通過。變速比例與聲畫限制見 [測試與驗收](testing-and-review.md) 及 [剪接到交付](post-and-delivery.md)。
