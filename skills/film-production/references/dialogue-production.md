# 對白短劇：從資產到可用片段

用於有連續角色對白的短劇、漫劇或寫實短片，以及這類片段的生成、補拍、剪輯與成本估算。只寫劇本時不必讀；MV 沿用指定歌曲母帶，不以本頁改動既有音訊政策。方法取自 S9 的製作組織，再依 S10–S11 的模型與節點邊界修正；未驗證作者的價格或成片效果。[來源與限制](sources.md)

## 沿用專案資料，補齊當鏡缺口

已有角色、場景、聲音或已接受 take 時直接沿用，不要求重做一套資產。首次建立路線或核心交流尚未驗證時，先在既有額度內選一個能暴露風險的小段落：單人一句對白；需要正反打時再測雙人接鏡；需要逐字口型時測固定配音驅動。這是選題方式，不是自動新增三次生成。

以鏡頭卡串起以下最小資料；可用一張表完成，不另造重複正本：

| 資料 | 需要保留 | 不應混用 |
|---|---|---|
| 角色／LOOK | 穩定 ID、版本、身份來源、當鏡需要的視角與服裝；參考圖逐一核對臉與比例 | 多視角設定板不是全角度一致的證明 |
| 空場景 SET | 布局、尺度、門窗、光源、時段；正反機位從同一空間推導 | 空景底圖與含人物的走位／構圖參考分開 |
| 道具 PROP | 尺度、持有者、手別、位置及前後狀態 | 只寫尺寸不能保證模型每格不變形 |
| 聲音 VOICE | 角色 ID、授權來源、聲線描述或參考音訊、版本；對白與驅動模式 | 聲線參考不是逐字台詞驅動 |
| 當鏡參考清單 | 資產 ID／檔案版本 → 身份、布局、構圖或聲音責任 → 實際槽位／標籤 | 不把多份矛盾場景一併傳入，期待模型自行選對 |

多視角板、正反打素材或反應鏡頭按實際需要建立，不強制每個角色出全套、不預先生一批用不到的圖。主場景參考指定一份；其他空間圖只有在工作流支援且責任清楚時加入，不將只准一張圖寫成所有模型的限制。

## 反打與光線：固定世界，重算畫面

反打是換攝影機位置，不是左右翻轉圖片。先記角色、桌、門窗、對話軸線與相機在同一空間的位置；再推導新機位的畫面左右、眼線、持物及遮擋。前一鏡的畫面左側不必在反打仍是左側，角色自身左右與手別保持。

光線鎖定實體來源，例如窗在房間西側、太陽時段與燈的位置、光質及色溫。換機位後重新描述其入畫方向，不能每鏡機械複製畫面左側來光而讓光源跟相機移動。明確設計的混色光或敘事變光可以保留，毋須全片只有同一光型。

寫提示詞時選當鏡必要的景別、視點、運動與光；不要為湊模板加入互相衝突的機位。固定機位可降低初測變數，但對白不能推拉、不寫光就一定平光、固定景別數量等，都不是已驗證的模型鐵律。

## 台詞、嘴部動作與聲音分開指定

保留已核准台詞的原文，固定說話角色 ID。依劇本標記解讀語意，不只依賴各製作習慣可能不同的 OS／VO 縮寫：

| 聲音意圖 | 畫面要求 | 聲音要求 |
|---|---|---|
| 當面對白 | 說話者可見時配合開口；聽者不代說 | 該角色的指定台詞、語氣與聲線 |
| 內心獨白 | 角色嘴唇保持閉合，表情承接心境 | 台詞仍有聲，以內心旁白呈現 |
| 畫外對白 | 說話者不在此畫面，入鏡者不代為開口 | 原角色對白持續，保留空間與時間關係 |
| 無聲反應 | 可見反應與刺激相符，沒有新增對白口型 | 是否保留環境音依聲音設計，不一律靜音 |

不要用不念出聲來表達閉嘴獨白，避免同時要求有聲又無聲。每段照抄聲線描述只能穩定條件，不能保證同一聲音。需精確台詞或聲音身份時，評估已授權的固定配音加驅動模式，先核對工作流能力；未支援時列後製或其他已授權路線，不假稱已對嘴。

台詞負荷以實際讀音、停頓與表演估時，不把每十字兩秒或五秒兩句當上限保證。未有音軌時標暫估，保留停頓與接鏡餘量。配樂通常在段落時間線統一處理，若專案要求原生音樂就沿用該設計。

## 生成段不是剪輯鏡頭

鏡頭卡以故事中的鏡號為準；一次生成任務用獨立段落／take ID。可一鏡多候選，也可一段包含多鏡，必須保留對照：

    剪輯鏡號 → 生成段／take → 原檔 source in/out → 時間線 in/out
    使用的角色／場景／聲音版本 → 實際參考槽位
    上一接受切出狀態 → 本鏡起終態 → 本次驗收與未決項

一段生成優先處理一個清楚的戲劇節拍。若要多鏡，分清每鏡目的、順序及預計時間，測試是否真的可控；不為符合模板強制合併 2–4 鏡。生成時長由工作流與當鏡內容決定，不固定所有模型都為 5–15 秒。

對白太長時可在剪輯中保持原對白音軌連續，切到相符的聽者反應或道具插鏡；這是覆蓋敘事，不是把失敗說話 take 改標通過。覆蓋鏡頭需承接同一時段、視線、道具、情緒與聲音狀態；優先取既有可用素材，補生成依原工單額度。

## 驗收與返工紀錄

先原速看並聽，再定位問題時間窗。逐項查角色與 LOOK、空間／手別／持物、事件因果、說話者、實際詞句、聲線、嘴部同步與接鏡。ASR、可解碼、首尾圖相似或解析度正確都不能替代實際內容驗收。

每次只更新有變化的 take；沿用專案狀態，不用文字檢查直接標 Owner 接受：

    段／take ID、鏡頭卡版本、seed、實際 prompt／模型／設定：
    結果：直接可用／裁切可用／待補／不合格／未檢查
    問題時間窗與證據：
    可用 source in/out、接鏡餘量、檢查者與接受依據：
    下一步只改哪個因素、剩餘候選額度與停止條件：

修復先評估可否剪去瑕疵且故事仍成立，再評估局部補拍，最後才重生整段；保留原 take 缺陷與衍生關係。補段要查接點兩側的畫面與聲音，不能只看補段自身。連續出現同一失敗時先回到參考、語意、布局或拆鏡診斷，不因還有餘額就原樣反覆重抽；達工單上限即停止。

字幕以實際接受的台詞／音軌版本為準。若生成改詞，先判斷是否仍滿足原劇本；經專案權限接受改詞後同步更新腳本與字幕，否則修復該句，不默默用字幕掩蓋。聲音、編碼與交付驗證沿用 [後期標準](post-and-delivery.md)。

## 用合格秒數估成本

以當前平台方案或當次計費紀錄為準。參考教程的套餐、贈幣、每次扣費只能標為未驗證假設；幣有不同來源／有效期時，不混成單一無條件匯率。

    生成直接費 = 全部嘗試的實際費用 + 局部補拍 + 升檔／後製服務費
    每合格成片秒生成費 = 生成直接費 / 最終接受且實際使用的成片秒數

分開記錄每次輸出長度、驗收可用範圍與時間線使用範圍。成片秒數按最終時間線有效區間的聯集計，多軌重疊不相加；有意重播可增加成片時長，但不增加獨立可用素材。另需估素材產出率時，按各原檔接受區間的聯集計「獨立可用素材秒數」，同一來源重用不重複計；兩種分母標清，不混為同一指標。尚無合格成片秒數時顯示無法計算，不能除以總生成長度報低價。只做圖像任務則用入選圖數，不硬換算秒數。

預算估計列明可用率／裁切損耗、嘗試數、實際尺寸、時長、採樣／加速、機型／費率及方案假設，隨實測更新。另列劇本、生圖、配音、排隊／載入、人工檢查／剪輯與儲存；生成費不冒稱完整製作成本。比較模型時採相近內容與驗收條件，不能僅憑 API 單價宣稱同品質價差。

## H3 或雲端工作流交接

只有選定 H3 時才查這一節；優先沿用現有已核對的 H3 執行技能與專案配方。這份製作指南不替代執行端的槽位、版本、模型與授權檢查。

- 綁定可取得的實際工作流／版本、模型來源、參考格式與設定。作者連結缺失時標明不可重現；上游 JSON 可作替代模板，但須另行核對，不稱作者原配置。
- @ 選單、Picture／Audio 標籤、首尾幀與聲音驅動依實際節點編譯；不假設把 @圖片1 當普通文字貼進任意 API 就會生效。
- 聲線參考與單一音訊驅動的上限依當次模式查證，不把全部模式的參考數量混用。
- 記錄完整寬×高、原生 fps／格數。社群超分／二採不等同官方 Regenerate-2K；尺寸變大不代表恢復原生細節，轉 30fps 也不等於原生生成 30fps。
- 研究來源只支持文件與程式所述能力；模型讀取、顯存、速度、口型、品質及扣費仍需各自實測。保留既有生圖、生成及發布權限，不由此頁擴權。
