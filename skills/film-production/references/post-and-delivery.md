# 從節奏粗剪到交付

剪接從前期開始，正式後期在已確認素材與時間線上進行。[來源 S1–S5、S8](sources.md)

## 前期 animatic 與覆蓋

用既有圖、草圖或文字卡搭成可計時的粗剪。MV 以指定歌曲母帶及 offset 為主時間線；音軌未定就用暫定段落標記，不能捏造精確對嘴位置。

每鏡問：新增了哪個資訊、反應是否有刺激、前後是否重演同一動作、誰的視點、需要哪個切點／插鏡。安排空間建立、主要動作及反應／插鏡是為了敘事，不是每場都要固定數量的景別。先用粗糙版本驗節奏，再投入昂貴生成。

## 粗剪、精剪、定剪

- 粗剪選能讓故事成立的範圍；原生 take 與選段分開。
- 精剪處理動作、情緒、音樂及聲音切點。反應需要保留到觀眾讀懂，不以平均鏡頭長度強迫切掉。
- 同鏡位延長、反打與跨場蒙太奇分開處理。A 尾幀正確不能保證 B 換機位的眼線與手別正確。
- 比較切點兩邊足以讀出動作的時間窗，必要時擴大，含聲音順播。窗口長度依動作，不定成通用秒數。
- 定剪需記版本及權限；定剪後改長度，要重查音效、音樂、對嘴、字幕及交付範圍。

插鏡與變速不能用來把原 take 的缺陷標成通過。新增插鏡保留同一故事狀態、接觸位置、手別、光與時間；需要新素材時按工單權限處理。

## 聲音是可編輯的獨立層

逐鏡分清歌唱、對白、畫外音、心聲與純反應。每個來源有版本、範圍及 offset，環境音、Foley、聲音事件與音樂可以分層調整。

「生成音不用」是瞳 MV 目前的專案決策，並非所有影片的通則。若專案核准使用原生音，也要查來源、詞句、身份、表演、同步與混音。歌曲母帶保留完整，不因影像生成或局部變速被換掉。組裝場次時避免嵌套音樂又在全片重複疊一份。

變速前決定受保護音軌與事件，處理後重新聽／看同步、接縫與表演。ASR 可提示詞句錯誤，不能證明情緒、發音自然或歌詞對嘴。正式語音／字幕仍遵守專案既有媒體驗證順序，不能用本技能取代。

## 後期處理要保留原生與衍生關係

字、介面及需精確的訊息另做可編輯層。先統一素材的色彩解讀及時間基準，再做匹配；8-bit 輸出轉成高位元格式不會恢復不存在的原始動態範圍。

放大、補幀、修臉、降噪與調色按當次授權及實際需要決定，不是每支都做。保留原生 fps 版本，處理後再查微表情、牙齒、瞳孔、手指、衣料與接觸速度；表面更乾淨不能掩蓋故事或拓撲失敗。不要把外部案例的 LoRA、付費修復工具或客製模型當成此專案已安裝的依賴。

## 交付前檢查最終匯出

依目的地規格表檢查，不把任一平台的解析度、codec 或 LUFS 變成所有作品的固定值。

| 層 | 檢查 | 證據 |
|---|---|---|
| 容器／影像 | 尺寸、畫幅、fps／時間基準、格數、範圍與可解碼 | 探測與解碼紀錄 |
| 聲音 | sample rate、聲道、響度、true peak、削波與實際可懂 | 測量＋所需聽審 |
| 內容 | 原速故事可讀性、身份、接鏡、表演、聲畫 | 時間碼、檢查方法與人工 verdict |
| 字幕／字層 | 詞句、同步、換行、可見性、遮擋臉／手／重要動作 | 最終匯出畫面及音訊 |
| 權利／發布 | 來源、接受依據、必要揭露、實際發布權限 | 專案指定 receipt／Owner 決定 |
| 完整性 | 成片版本、來源及衍生 manifest、SHA-256 | 清單、hash 及目標副本核對 |

時間線中有字幕或 API 回報成功，不代表成片上真的看得到。編碼、混音、變速或修圖後，重查受影響項目及接鏡；不對完全未變更部分盲目重跑所有測試。

## 交付與可恢復工程

除播放檔，按任務保留可修改剪輯工程／時間線、必要 .blend、素材對照、依賴、聲音分軌、字幕／字層、生成設定與接受紀錄。媒體放 Git 外，repo 記路徑、版本與雜湊，不能把本機憑證包入工程。

備份不能只報檔案已複製。需要驗證可恢復時，在獨立副本 relink，核對真正在用備份路徑，重建代表性段落並比較；不得靠原工作目錄仍存在來假稱恢復成功。未做就標未驗證，不自動刪來源。

交付後記返工原因及成本：嘗試數、入選秒數、生成視窗、人工檢查／修訂、後期時間與存放量分開。第一部完成後回看哪些設計或驗收缺口造成最多返工，再修方法。
