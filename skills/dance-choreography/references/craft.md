# 編舞方法

## 動作從哪裡來

- 人物的日常動作：掃地、倒茶、鞠躬、打卡、敲鍵盤。把它放大、加速、重複、放到拍上，就成了舞。
- 歌詞裡的畫面：挑一兩個最有記憶點的字，不要整句翻譯成手語。
- 人物的處境：被迫、逃跑、硬撐、假笑。先想身體怎麼反應，再放到拍上。

## 主打動作

韓國流行舞稱為 포인트 안무：通常放在副歌，短、好認、能配合歌曲概念，也讓觀眾學得會。

設計時先定下面三件事：

1. 誰在主導這個動作（自己、看不見的力量、別人）
2. 從哪個部位開始（手腕、肩、胸口）
3. 結束時定在哪個姿勢。定格的姿勢通常就是別人記住的那張圖

## 動作發展

| 手法 | 做法 | 可以表達 |
|---|---|---|
| 重複 | 同一動作再做一次 | 記憶、強迫、習慣 |
| 切片 | 只做其中一段 | 猶豫、失效、回想 |
| 倒放 | 順序反過來 | 收回、被重置 |
| 放大縮小 | 改變動作範圍 | 情緒升降 |
| 換高度 | 高、中、低 | 地位、疲憊 |
| 換朝向 | 對鏡頭、側身、背對 | 親近、逃避 |
| 換速度 | 加快、放慢、頓住 | 緊張、失控 |
| 換部位 | 手的動作改由頭或肩做 | 幽默、延伸 |
| 換力道 | 硬、軟、突然、拖曳 | 情緒質地 |
| 換主導者 | 被拉變成自己做 | 劇情轉折 |

## 時間

- 重拍、弱拍和切分都可以用。全部打在正拍上會變得機械，除非機械感就是想要的效果。
- 一段裡要有快慢對比，快動作之後的停頓最醒目。
- 主打動作前留半拍空檔，讓人看得出它開始了。

## 空間與身體

- 動作要先有重心，再有手。只有手在動時看起來像在比手語。
- 轉身前腳要先站穩，跳躍前要先有下蹲準備。這些因果也要寫進提示詞，否則身體會像被搬動。
- 不要長時間左右對稱，也不要讓手長時間擋住臉或嘴。
- 裙擺、長髮和外套會跟著動作走，大動作要預留畫面空間。

## 喜劇動作

- 臉和身體唱反調：身體精準，臉不情願。
- 用動作做結果：想走出去的一步被拉回原位，觀眾會立刻看懂。
- 動作和表情差一點時間：先做完才發現自己在做。

## 底線

靠人物和音樂吸引人，不靠性暗示。角色未確認是成年人時，不寫帶性暗示的動作。寫得克制也能降低平台和模型過濾的風險。

## 常見錯誤

- 一支短片塞太多動作，模型只會做出前面一兩個
- 每句都比字面意思，看起來像在演猜字
- 動作大小從頭到尾都一樣
- 主打動作每次都一模一樣，沒有跟著劇情變
- 全身鏡頭放小動作，手勢根本看不見
- 手指比數字或細手勢放在遠景
