# MV 呈現方式

呈現方式在寫 MV 劇本時和創作者一起討論決定。這份技能提供討論用的問題和案例，不是選單，案例以外的做法一樣可以。

## 原則

- **沒有預設形式。** 整首都在跑步、只拍窗外風景、主角是一盒牛奶、歌曲停下來演一段再響起，都是成立的 MV。
- **先討論，再測試。** 測試只回答做不做得到。測過不代表會用，沒測過也不代表不能選。
- **創作者的想法優先。** 對方提的方向先認真展開，不要因為某個工具已經測過就往那邊帶。
- **工具限制是討論資訊，不是前提。** 可以說明某條路目前缺什麼，但不要先把它刪掉。

## 討論時要決定的事

一次問一題，順序不拘，也可以先空著。答案欄只是舉例。

| 問題 | 例子 |
|---|---|
| 畫面主要在看什麼？ | 歌手演唱、人物做別的事、物件、風景、螢幕畫面、文字、動畫、靜態插畫 |
| 故事和歌詞是什麼關係？ | 照字面、平行的另一個故事、刻意反差、只取情緒、只有一個點子沒有故事 |
| 歌和影片的時間怎麼走？ | 從頭播到尾、中途停下演一段再響起、歌前歌後加戲、重新剪歌、一鏡到底 |
| 除了歌還聽到什麼？ | 沒有、環境音、音效、對白、完全靜音 |
| 文字要做什麼？ | 沒有、字幕、飄過、變成場景裡的物件、文字本身就是主角 |
| 主角怎麼出現？ | 全程出現、只看背影、只出現在螢幕或照片裡、由別人或物件代替、不出現 |

## 流程

1. **讀完整歌詞和歌曲結構。** 用一句話講這首歌想讓人感受到什麼，請創作者糾正。
2. **提出方案。** 創作者提過的想法放最前面。方案之間要差很多，至少一個沒有演唱畫面，一個改變歌曲的時間結構。每個方案一兩句，讀完就看得到畫面。
3. **一起討論。** 可以混搭或全部推翻。需要參考時讀 [forms.md](references/forms.md)，舉例時說明自己只讀過資料、沒看過影片。
4. **方向定了才談可行性。** 列出這個方向已證明、未證明和要測什麼，再提最小的測試。
5. **寫進劇本。** 每一段都記錄畫面主體、歌曲時間、聲音、文字和人物。有人物開口時，再標記歌唱、對白、反應或畫外音。

歌曲會中斷時，另外記錄停點、怎麼停、中斷多久、這段演什麼、怎麼接回音樂，以及影片總長度。影片版和純音樂版可以不同，要分開記錄版本。

## 這份技能的限制

案例多半來自百科、評論和搜尋摘要，寫這份技能時沒有實際看過這些影片，也沒有找到導演逐步說明形式選擇的一手資料。可信度在 [forms.md](references/forms.md) 逐項標明。
