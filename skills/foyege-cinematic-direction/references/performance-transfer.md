# 表演參考、發音與剪接選擇

需要拍攝／選擇表演參考、轉移到另一角色，或處理說話時表情跳動時閱讀。這是對 Foyege「人物目的 → 可見反應 → 控制與殘留」的補充，不替代既有 [微表演卡](microacting.md) 與 [詞級觸發](acting-beats.md)。以下工作卡及案例為本技能原創；來源為 [T19–T22](tutorials.md#2026-11-09-第二輪表演研究)。

## 先選表演，再做轉移

選素材先檢查人物在做什麼：當下想影響誰、刺激在哪裡、策略是否改變、結尾留下什麼。外形接近或動作豐富，不能代替這些條件。參考只有動作、缺少關係與刺激時，先補導演設計，不直接把它當成合格表演。

| 檢查 | 記錄與處理 |
| --- | --- |
| 鏡頭相容 | 景別、視角、臉／身體可見範圍接近成片用途；再核對選定工具的裁切與起始姿態要求 |
| 行動相容 | 接觸、姿態、道具及支撐是否能對應；近景臉部驅動不自動提供手部接觸 |
| 表演相容 | 原目標、刺激、主要變化、收回／殘留與終態，哪些保留、刪除或需重設 |
| 聲音相容 | 對白／歌曲是否同版本；無對應發音時不要讓驅動片替換鎖定音軌或口型責任 |
| 角色相容 | 角色比例、風格、活動範圍是否容許該姿態；超出資產能力時改演法或拆鏡 |

自攝時依成片景別安排相機，讓重要部位與實際道具互動可辨。每次錄完先回看，指出一項要改的選擇，再錄下一版。已有合格 take 就沿用，不要求為了流程重拍。狹義頭像驅動仍服從其工具輸入條件；不能把接近成片機位的拍攝建議硬套到只接受正面起姿的工具。[T20](tutorials.md#t20-表演參考的選取與分析)

動畫轉譯保留刺激、目標與因果，幅度和姿態按角色調整。真人一次側頭可能讓大眼角色失去可讀眼線；改小頭幅、保留目標，或以相容機位補拍。這是需要驗證的改編，不宣稱自動轉移會完成。逐幀照抄、全臉同比例放大都不是預設策略。

## 表情基準與發音

先定這段話開始時的表情，以及真正改變它的事件。發音時讓嘴型在該表情傾向內運動，保留必要開合與下顎活動；「維持表情」不等於固定嘴角、鎖嘴或禁止眨眼。句子沒有新刺激時，不因每個音節重新演一次驚訝、微笑或崩潰。[T19](tutorials.md#t19-表情基準中的發音)

分三層檢查：起始表情是否承接、發音是否與音軌相容、關鍵詞是否真的帶來新變化。眼、眉、嘴不必共用同一速度曲線，也不為了錯峰而強加延遲；追蹤移動物件與一次目光切換分別處理。教學中的影格數不直接換成所有 fps、角色或生成模型的精確參數。

原創例：成年接待員 C1 想讓訪客稍候，起初有很淡的職業笑容。她說「請在這裡等我」時保留其表情傾向，嘴依實際字音開合；聽到畫外「他回來了」才出現一次視線停住，句尾後笑意退去。沒有音軌就只交事件順序。鎖定 MV 同理保留唱法，情緒變化由可用的非口部反應或唱後間隙承擔。

## 潛台詞的導演選擇

從劇本線索、人物目的與阻力推導角色採取的策略，先寫成「拖住對方、試探、保護、敷衍」等可演行動。沒有確定解讀時，可提出少量標明差異的候選，不把猜測寫成已確認設定。[T21](tutorials.md#t21-從潛台詞到可演策略)

角色想隱瞞什麼，不代表每一項內心想法都要加一個臉部動作。選擇該鏡需要洩漏多少、由誰看見，保留有目的的克制。觀眾可以尚未確定原因，但仍應能跟隨眼前行動。表情不作現實人物心理診斷。

原創例：同一句「票還在這裡」，A 版是拖住同伴，手留在票旁等對方回頭；B 版是結束談話，把票推到對方可取的位置後收手。先按劇本選策略，再設計眼神與停頓，不同時塞入互相矛盾的兩版。

## 反應素材要在場景中成立

覆蓋一個人物或事件時，交代鏡頭要取得的反應、行動或話語效果；不是有近景就算取得表演。原速先看候選片段，再放回前後聲畫檢查：刺激抵達、角色處理、主要變化與尾端承接是否成立。[T22](tutorials.md#t22-以表演目的檢查覆蓋)

原創剪接診斷：某反應 take 在「停下」之前已轉頭，若設定是聽見該詞才轉，就不能僅因表情漂亮而接受。先查是否有相容的可用區間，再選其他 take、移動未鎖定的切點或補鏡；音軌／劇情已鎖定時保留它們。角色早已預期該事時可以提前反應，但需有劇本依據。不要用任意延時、循環或定格偽造不存在的處理過程。

只在確實需要選 take 或修剪接時記錄：鏡頭用途、來源與可用區間、接收到的刺激、進出狀態、前後聲畫中的通過／需修正／未檢查。連續性規則沿用 [事件覆蓋](scene-coverage.md)，不新增每句必反打或每個反應必切鏡的要求。

## 表演、機位與生成分開驗收

需要參考片驅動、多視角表演或大幅運鏡時，先分開兩條時間線：角色在世界中做什麼，以及攝影機如何觀看。機位繞到人物另一側，不代表角色應自動看向鏡頭；維持原具名目標，只有表演設計要求時才改變視線。主要微反應發生時檢查眼睛、嘴角與殘留是否仍可見；必要時先穩定近景，再移動機位。

此工作法是本技能從 [T23 多視角表演案例](tutorials.md#t23-多視角表演與-ai-轉譯案例) 提煉的製作延伸。案例的俏皮大表情、快推與環繞可作風格選項，不要求克制對話或 MV 獨白照搬。

### 先標清拍到了什麼

記錄參考真正覆蓋的臉、手、身體、接觸與視角。下半身未拍到、新增背面或被遮住的手，都標成待補素材／生成補全／來源未知，不因成片看起來完整就改成「原始捕捉已驗證」。新增部位另驗解剖、接地、接觸與身份。只有成片時，保留原始表演及中間重建未取得，不倒推它們已通過。

4DGS 類資料可表達隨時間變化的三維外觀並支援新視角，不自動提供可編輯臉部 rig、逐肌肉控制或無限制機位。骨架／臉部動捕、動態多視角重建與影片驅動按實際資料和介面分流；臉部動捕也能轉移表演，不能概括成只有 4DGS 能保留表情。

### 對齊事件，再比較各層

使用已有素材，不為填表新增拍攝或渲染。只有參考與結果兩層就比較兩層；沒有中間預演時標「未使用」，未知時標「未取得」。

| 層 | 保留的證據 | 檢查責任 |
| --- | --- | --- |
| 原始表演／驅動片 | 素材版本、時間範圍、可見部位、刺激與起終狀態 | 原表演是否真的含有需要的反應，哪些內容沒有拍到 |
| 中間預演／重建渲染，如有 | 來源版本、機位、時間對應、裁切及已知補全 | 轉視角或轉譯後，目標、眼頭先後、接觸與主要表情是否仍可讀 |
| 最終生成 take | 實際模型／工作流、使用的輸入槽與版本、原生輸出及觀看版本 | 對齊同一事件，驗身份、幅度、先後、保持、補全部位與接鏡終態 |

用穩定事件 ID 綁刺激與反應，時間依各檔實際 offset、裁切、fps／時間戳及變速關係對應。改了機位或慢放，就不能只拿相同影格號當成同一拍；嘴角峰值相似也不能代替整個反應鏈。

沿用表演卡，必要時補下列短記錄：

```text
事件 ID／必須保留的反應：
參考片版本與區間／刺激點：
角色目標、主要變化、保持及終態：
攝影機時間線／關鍵反應的可見區間：
實際捕捉範圍／待補或來源未知部位：
中間素材及時間對應：未使用／未取得／實際版本
輸出 take／對應事件區間：
分項結果：通過／需修正／未檢查＋具體證據
```

原速確認表演是否成立，再逐幀定位偏差；抽幀可指出取樣狀態，不能證明完整連續性。只看到最終影片時，不宣稱真人表情被無損保留。能否接下一鏡仍以已接受的最終 take 終態為準，不以驅動片或預演尾幀代替。

### 以本機已有路線實作

先用已授權且合格的表演片，核對現有 Wan Animate 2 等工作流實際接受的驅動、角色圖與控制方式；幾何機位有風險時再用現有 Blender 預演。沒有可轉視角的表演資料或臉部資產時，可改穩定近景、既有反應插鏡或補拍，不能把單視角影片／無臉白模當成任意角度的精確臉部表演。分開的參考是否能同時送入模型，依實際輸入契約核對。

十五相機、特定 4DGS 套件與 Seedance 均不是本技能依賴；不由案例自動安裝、訂閱或上傳。執行前仍沿用本機資源、GPU 排程與既有授權。

原創草案：C1 聽完「再來一次」後，維持對 C2 的注視，笑意退去一點，再恢復較淡的弧度。把這次反應獨立成事件；先讓它在穩定近景可辨，展示性的繞背安排在主要反應之後。若現有參考只拍到胸口以上，改全身時另列下半身與接地待驗。片長、角色圖及音軌未綁定，這是製作方案，沒有生成驗收主張。
