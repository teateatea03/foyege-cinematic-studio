# 跨部門製作、排程與交接

多鏡作品、需要多人協作、排生成順序或交接後期時使用。單鏡提示詞、純劇本與小修直接完成任務，不要求填整套劇組表。沿用專案已有 BREAKDOWN、SHOTLIST、CONTINUITY 與責任表；可用同一張表補欄位，不另造第二份正本。

實際劇組會依規模合併或細分職位。同一人或同一套工具可負責多項功能，仍要知道各項交付由誰製作、誰檢查、下一步交給誰。常見職能依據 [T38–T44](tutorials.md#2026-11-09-劇組職能研究)，以下 AI／混合製作表單是本技能的改編。已有 film-production 時沿用其十二階段及鏡頭卡；未安裝時，本頁可獨立使用。

## 從本次交付反查依賴

先定交付物，再找會改變其結果的前置項目。只有實際影響當前工作的缺口才阻擋它；其他鏡頭、文字設計或可逆整理繼續。

| 交接 | 要明確的內容 |
| --- | --- |
| 製片／製作協調 → 各部門 | 用途、交付版本、片長／畫幅、截止與資源／候選上限；已鎖定項與未決項 |
| 編劇 → 導演／副導 | 場次、故事日、必要事件、知情順序、台詞／音軌與可省略的裝飾 |
| 美術／造型／道具 → 攝影／場記 | SET／LOOK／PROP 版本、實際視角、入出狀態與重置方法 |
| 攝影／燈光 → 生成／VFX／調色 | 機位、光源、視野／焦點、顯示基準、參考負責層與可見區間 |
| 聲音 → 表演／剪輯 | 音軌版本、聲源、事件觸發、同步責任、需補的聲音及保持段 |
| 場記／DIT → 剪輯／後期 | 實際 take／可用範圍、檔案／時間基準、缺陷、檢查方式與接受依據 |
| 剪輯 → VFX／調色／混音 | 定剪或工作版本、source／timeline 範圍、餘量、效果責任與回交規格 |
| 後期統籌 → 品管／交付 | 各返回版本、替換清單、同步／內容驗收、母版與平台版及未檢查項 |

「已設計」「素材已收到」「可執行」「實際執行成功」「內容通過」「專案已接受」分開；沿用既有狀態名稱，不另建立互斥的狀態機。文件齊全不代表模型、聲音或影像已驗收。接受權限依專案，不能因換成某個部門名稱就擴權。

## 拆解到可交辦的工作

```text
場次／故事日／劇本與音軌版本：
本次要交的鏡頭／時間線版本：
必要敘事事件及承接來源：
所需 SET／LOOK／PROP／VOICE／動作或相機資產：
每項：目前版本 → 負責人／工具 → 交付物 → 檢查者
前置依賴：已收到／待確認／不適用，附依據
最高風險與最小可辨測試：
可改項、已鎖定項、候選／資源上限：
下一個接收者與可接受的交接條件：
```

角色圖、聲音、場景、身體／臉部 rig 的存在與所需用途適配分開。選角／聲線比較只在需要選擇時做，以指定台詞、姿態、視角或表演任務比較已授權候選；沒有適配測試不稱角色已能完成全片。來源與用途記錄沿用 [專案維護](project-stewardship.md#素材用途與署名紀錄)。

## 排製作順序

以依賴、故事必要性、剩餘風險與實際資源排隊；不照劇情順序盲目逐鏡跑，也不只因同模型能連跑就忽略未定素材。

- 先選暴露主要問題的小段落，讓畫面、表演、聲音與接鏡相遇。已驗證項直接沿用，最高風險層才測。
- 共用 SET／LOOK／模型可成組準備，減少換裝、重置或載入；每鏡仍綁自己的狀態與版本。估時分準備、載入／排隊、執行、檢查、修訂，不拿一次暖機秒數保證整日產量。
- 實拍通告需要時間、地點、演員／服裝、設備及負責人；AI／動畫工作單改記資產、工作流、裝置、負責步驟與輸出位置。兩者需要多少就寫多少，不編造場地、演員空檔或可用顯存。
- 支援 GPU 的工作依既有單卡政策與當下排程。同卡重工作序列化，GPU 忙碌時做獨立文字準備；不自行停其他工作、退成 CPU 生成或改用另一張未指定卡。
- 到當次候選或時間上限仍未達標，保存結果與未解原因，回到素材、控制方式或拆鏡。不得為湊進度把技術成功改標為內容通過。

只有本次真的執行時才記實際耗時與可用範圍。成本沿用專案方法，分清總生成量、獨立可用素材與最終使用範圍；未知費率／可用率保留假設，不報虛構預算。

## 每次 take 的場記與重置

```text
shot／take → 導演卡版本 → 本次實際使用素材與設定
拍前重置：人物位置／視線／服化／道具／光／聲音起點
拍後實際結果：可用 source in/out、入出狀態與缺陷時間窗
技術檢查／內容檢查／接受狀態及證據
下一鏡：可直接承接／需調整／尚待確認，交給誰
```

重拍回到指定入鏡狀態，不把上次失敗 take 的尾態當下一次起點；敘事續拍則承接已接受來源。道具的磨損、折疊、液面、衣服扣位、妝髮與汗濕等，依畫面需要記錄。生成式重置是正確參考／入鏡狀態，不能以「同 seed」代替。實際外觀與聲音檢查見 [部門交接](department-handoffs.md)。

## 後期回交與變更

剪輯器的「定剪」是具版本的約定。工作中變更可依既有授權進行，記錄受影響範圍即可；不把定剪誤當永久不可改，也不靜默替換所有已接受鏡頭。

交給 VFX／調色／聲音時，附 shot ID、實際來源版本、source in/out、timeline in/out、fps／起點、餘量定義、效果責任與參考審片。沒有餘量便標明，不捏造通用秒數。回交依 shot／版本與時間範圍重新套回，先核對幀數、方向、色彩處理與聲音同步，再在前後鏡檢查。

| 改動 | 優先回查 |
| --- | --- |
| 換 LOOK／道具狀態 | 同故事日與相鄰鏡、身份來源及反打 |
| 換 SET／主光／機位 | 空間、陰影、反射、遮擋、眼線與 VFX 相機 |
| 改片長／切點／變速 | 音樂、對白、口型、字幕、VFX 範圍及後段同步 |
| 改顯示／色彩處理 | 審片基準、調色回交及母版，避免重複套用 |
| 改劇本事件／台詞 | 知情、反應、覆蓋及音軌，連同受影響素材版本 |

返工單寫「問題與證據 → 所屬部門／層 → 本次只改什麼 → 交回哪版 → 要重看哪些接點」。原始缺陷與舊版本保留。素材、音訊與成片的具體檢查沿用 [交付驗收](media-handoff.md)，封存與恢復沿用 [專案維護](project-stewardship.md)。

## 實拍與專項責任

AI 製作不需要為表格虛構實體劇組。作品真的涉及外景、搭建／懸吊、特技／煙火或需要專門照護的表演時，才列實際場地、設備、執行者及必要專項條件，交由有資格且已授權的人負責；數位預演不能充當現場操作核准。演員／聲音／素材的取得與發布權限沿用專案，技能盤點本身不聯絡、聘用、購買或發布。
