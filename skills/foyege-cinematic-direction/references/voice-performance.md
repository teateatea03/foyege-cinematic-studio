# 配音表演、固定選角與局部重配

用於角色對白、畫外音、旁白或聲音改稿，接回 [話輪與觸發](acting-beats.md)。優先用專案已有 TTS、錄音與剪輯工具；Drama3 是本次研究的候選實作，不因讀到教學就替換正式聲線或安裝新模型。瞳 MV 已鎖定的主唱音軌保持原版，另案對白／獨白才用這份交接。

## 先固定聲音身份與三份文字

每個角色綁 `角色 ID → 聲音版本 → 參考組／來源錄音 → 實際 speaker 槽位`。採用有權使用的錄音，保存原聲及轉錄校稿；顯示名稱相同不代表同一版聲音。新音色版本只影響明確改綁的工作，舊 take 保留原快照。

分開保存原始台詞、實際朗讀稿、顯示字幕。數字、縮寫、人名或讀音替換只進朗讀稿，保留對照，不能默默改寫原稿。台詞行 ID 穩定，排序或分鏡改動不重編已接受台詞的身份。

## 讓聲音表演有可執行的目的

沿用導演卡，不另寫只有「更悲傷」的要求。記錄角色在向誰爭取什麼、觸發詞、重音、音量／語速走向、呼吸與停頓，以及哪些表面控制仍維持。音訊方向與畫面動作分欄，TTS 不負責抬眉、眼神或手勢。

下列為本專案原創交接例，沒有生成音訊，時間需綁定實際接受版本：

| 欄位 | 原創例 |
| --- | --- |
| line／角色／聲線 | L014／C1／VOICE-C1-v2，參考組 ref-A，檔案待綁定 |
| 原稿 | 我沒有同意。 |
| 聲音目的 | 阻止對方離開，但保持表面平靜；重音在「沒有」，句尾收住 |
| 畫面 | 聽見對方的觸發詞才看向對方；說完後嘴角回復，手仍握著椅背 |
| 保留項 | 詞句、角色聲線與已接受的上一句；不添加笑聲或額外台詞 |
| 時間與聲畫交接 | 音檔版本、source in/out、實際詞邊界、呼吸／停頓與尾端餘量 |

把這些意圖編譯成所選工具真實支援的方向／風格欄；不要把整張工作卡原樣塞入朗讀文字。Drama3 T8 的 Scene 使用角色名或 speaker 標籤綁定，單句方向另有作用域；改稿可覆蓋舊情緒／語速前綴，先保存原版本，檢查新舊要求是否衝突。這是版本特定的控制方式，不是所有 TTS 共通標籤，也不保證固定秒數。

## 選擇生成與上下文單位

- 獨立逐句：適合定位字詞與單句候選；逐句通過後仍要連起來聽，避免每句重新起情緒。
- 逐句帶上下文：指定真正採用的前句／本角色錨點 take 與版本，不能只填文字就宣稱保留聲音上下文。前句、聲線、模型或設定變動後，標出下游待重查範圍。
- 同場一起／按角色：適合工具能處理的場景或角色單位。它們的續做與失效單位可能大於單句；不以逐句模式的復用規則套用。
- 使用者已有已接受錄音：以原音為準，不為套模型重做整段。需要固定音軌對嘴時交給已核對的驅動工作流，TTS 成功不等於影片同步成功。

## 局部重配保護已成立區間

綁定來源 take、內容雜湊、完整目標台詞和實際選區。用詞對齊定位後回到原速聽聲，檢查子音、換氣和殘響；可見波形不等於正確字界。不要對著右側另一候選的波形，修改仍指向舊來源的選區。

工具聲稱選區外 PCM 不變時，另核對前綴／後綴樣本、取樣率、聲道與改稿 manifest；插入長度改變後比較對應的後綴區間，不能沿用舊絕對時間。這只證明保留範圍，不證明接縫自然。工具不支援時以另存候選、替換與交叉淡化處理，保留受影響範圍並聽審。

## 選片、時長與交付

候選沿用工單上限；在匹配的聆聽音量下比原稿正確、聲線、重音、呼吸、話輪及接縫，原始輸出保留。ASR、說話人相似度、LUFS 或單一 seed 都不能代替演技／自然度判斷。

先報實際時長與溢出，再依創作決定改稿、重錄、留白或允許的變速。語速方向與 target duration 不保證精準落秒；超長台詞不能靠裁字尾達標。補靜音按整數 sample count；重採樣／變速後重算詞邊界、字幕和畫面觸發點。

交付 accepted take／line 對照、原始與處理音檔、各角色分軌、完整時間線、字幕、實際取樣率／聲道／sample frames，以及聲音版本、編碼與處理紀錄。分軌保留同一時間原點及空白；不能把每個角色的句子各自貼緊起點後宣稱已對齊。

## 新舊模型比較

用相同原稿、參考錄音／正確轉錄、角色映射、方向與候選額度比較，列每組模型及其匹配 head／Codec 批次；模型與 head 一起換時記為配方比較。相同 seed 不保證跨模型產生可逐樣本對照的聲音。先對齊聆聽音量，分別檢查字詞、聲線、重音、呼吸、情緒變化、長段一致性和接縫；不由較長／較短波形推定更自然。

單一展示或少數種子不建立全任務排名，也不自動替換舊配方。保留原始版本、失敗和未聽審項；是否採用新模型由本案的實際比較決定。

## Drama3 的研究邊界與來源

本次檢查 [T8 原始碼快照](https://github.com/T8mars/Comfyui-Drama-3/tree/0c57de542e5d1b6c55485cfaa97e13e1d536a823)：角色映射、方向編譯、上下文、交付與 19 份工作流；以上工作卡為本專案的原創適配。文件將 0.3.3 主模型／head 綁到官方 `78e5ab7` 批次；代碼更新不等於權重同步，FP8／W4A8、head、Codec 和 runtime 按實際版本核對。這些 T8 權重需其原生 loader，不是任意 Transformers／GGUF 啟動指令可直接使用。

本機原有能力不足時先列缺件和資源成本，不照搬整合包的 Python／Torch 版本去改 ComfyUI。RAM 專家放置、VRAM cache 與整體占用分開；後端實際生效與回退需看執行證據。GPU 忙碌時停留在稿件與交接準備，既有專案的配音、字幕與驗收規則優先。

[使用者提供的 12:31 教學](https://www.youtube.com/watch?v=wb9Vxnzkz50) 可見同題新舊語音比較及 Studio 展示。本輪字幕請求遭 HTTP 429，僅看畫面取樣並查原始碼，未獨立聽音／轉錄，也未生成或測試聲線；不判定新版更自然、克隆更像或 5080 可用。程式、轉換權重與參考錄音各有授權，公開本頁不附權重或原教學音訊。
