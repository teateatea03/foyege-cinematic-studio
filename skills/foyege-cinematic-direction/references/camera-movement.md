# 運鏡：目的、路徑、節拍與表情

需要移動相機、變焦、移焦或設計移動後的接鏡時使用。先交付該鏡頭需要的選擇，簡單單鏡不必填完整表。這是對 Foyege 空間／外觀／表演分工的製作補充；新增方法不歸為作者原話。來源及閱讀範圍見 [T34–T37](tutorials.md#2026-11-09-運鏡研究)。

## 先選目的與落點

先寫「移動後觀眾多知道什麼／更看得見什麼」，再選機械動作。跟隨人物、揭露資訊、強調心理變化、交代空間與 MV 的音樂風格都可以構成理由；角色站著不動也可有運鏡。固定機位是有效選項。動作幅度與情緒沒有一對一公式，不把推近必然等於悲傷、手持必然等於真實當成規則。[T35](tutorials.md#t35-攝影師的運鏡選擇)

落點需要可剪輯：開始／結束景別、觀眾的注意目標、最重要的反應在哪裡看見。為無關物件多繞一圈可能使剪輯只能刪掉開頭；先確認這段移動承擔的資訊，不以昂貴器材感代替用途。

## 分清移動的量

| 選擇 | 實際改變 | 導演需指定 |
| --- | --- | --- |
| 固定 | 機位、朝向與焦距保持 | 人物如何在框內變化、留白與保持多久 |
| Pan／Tilt 搖攝 | 固定機位，水平／垂直改朝向 | 從誰到誰、揭露順序、開始與落點構圖 |
| 推軌／拉軌 Dolly | 相機向場景靠近／遠離 | 路徑、人物距離、背景視差、是否固定焦距 |
| 橫移／跟拍 Truck／Track | 相機平移，可配合人物走位 | 世界方向、跟隨哪個目標、相對距離與前景 |
| 弧移／環繞 Arc／Orbit | 相機沿人物周圍改位置 | 世界平面中的路徑、起終角度、半徑、朝向與跨軸 |
| 升降／Crane | 相機高度改變，可同時平移 | 起終高度、揭露的空間、俯仰與是否越過遮擋 |
| Zoom 變焦 | 固定機位時改焦距／視野 | 起終焦距或景別、機位是否保持；不同於推軌 |
| Rack focus 移焦 | 焦點距離／目標改變 | 焦點從誰到誰、何時清楚；不稱為相機平移 |
| 手持／穩定器質感 | 運動的穩定程度與細部擾動 | 保留何種呼吸感、幅度與可讀性；不是額外的路徑名稱 |

基礎定義參考 [T34](tutorials.md#t34-相機移動與變焦)、[T37](tutorials.md#t37-靜止搖攝與跟拍)。表中選擇卡與風險檢查為本技能延伸。先選主運動，再加入確有用途的朝向、焦距或焦點變化，避免同時堆疊互相矛盾的控制。

## 焦距、距離與透視

固定相機位置而變焦主要改變取景範圍與影像尺度；移動相機才改變觀察位置與前後景的透視關係。數位裁切不提供新視角或被遮住的資訊。鏡頭毫米數須配合感光元件／sensor fit、畫幅與裁切記錄，不把某個焦距當作各模型通用的外觀保證。[T34](tutorials.md#t34-相機移動與變焦)

本機 Blender 的理想透視例：36 mm sensor width、水平 fit、16:9；主體與等高背景相距 6 m。50 mm 相機由距主體 6 m 推至 3 m，與機位維持 6 m、50→100 mm 變焦，可取得近似相同主體尺寸，但背景／主體投影高度比前者約 1/3，後者約 1/2。這是指定幾何的結果，不是所有場景的固定比例。

Dolly zoom 要同時控制距離與焦距。固定 sensor、主體尺寸及朝向時，可用「焦距／主體深度近似不變」作初始設計，再量主體畫面尺寸；主體走動、轉向或偏離畫面中心時需重算。它不是只有一句「眩暈感」便已建立的控制。沒有相容控制或測試預算時，交付草案與缺口，不假稱已精準實現。

## 起動、移動、落定與保持

角色事件與相機事件分開寫，再對齊兩者：

- 起動：由人物走動、聲音、資訊揭露、心理轉折或音樂段落觸發；沒有音軌時用相對事件。
- 移動：明確方向、路徑與速度變化。慢不是必然均速，快也不等於每格亂晃。
- 落定：在哪個景別／位置減速或急停，與人物抵達、回頭或停步的關係。
- 保持：讓眼神、嘴角或殘留有可讀時間，再移動或剪接。保持相機不代表凍結演員或禁止眨眼。

The Film Look 的停步教學支持把身體行動轉向臉部細節的落點思考；它不是每個反應都必須「推近再急停」的規定。[T36](tutorials.md#t36-移動後停步與反應)

重要微表情若被快速環繞、遮擋、出焦或大幅身體運動蓋住，優先安排可見區間：可先落定再演、保留慢移但維持眼睛可見，或另取近景。風格要求持續運動時照其需求設計，不能一概強制鎖鏡。角色仍看原具名目標；相機繞到另一側不等於眼神自動追鏡。[表演與機位驗收](performance-transfer.md#表演機位與生成分開驗收)

## 原創運鏡卡

```text
鏡頭／敘事或音樂用途：
依據：劇本事件／音軌版本與 offset／尚未綁音軌
起始 → 落點：景別、主要讀點、前後景、畫幅
相機位置路徑：世界座標或可理解的相對路徑
相機朝向／look-at：目標與切換條件；角色眼神目標另列
距離／高度／焦距與 sensor 或視野：固定哪些、改哪些
時序：起動 → 移動／加減速 → 落定 → 保持
表演可見區間：哪個眼神／嘴角／手部事件必須看見
焦點與穩定性：焦點目標、是否移焦、手持擾動範圍
接鏡：結束方向、人物與相機的運動進度、剪接餘量
執行：文字／可用的原生相機控制／Blender／拆鏡
驗收與缺口：指定測什麼；素材未提供與未實測分開
```

位置、旋轉、焦距與焦點分別記錄。以秒描述時標 fps：影格 1 對應 t=0，兩個關鍵格的時間差為 (終格−起格)/fps；N 格影片時長為 N/fps。兩者不要混用。MV 沿用鎖定音軌，不為湊運鏡修改唱法或任意平移聲音。

## 編譯到本機資源

- 文字／I2V：把首圖已有構圖交給素材，文字寫後續主運動、落點與表演。毫米、公尺與秒數是導演意圖，除非實際介面有對應控制且已測，不能聲稱模型會精準遵守。鏡頭動詞不當作各模型共同 API。
- 原生相機／深度／姿態控制：先查已裝版本、節點 schema 及工作流確實接受什麼。相機軌跡、骨架與角色外觀各有責任，不能拿姿態控制宣稱已鎖住相機。RefMod 參考檔亦不自動提供相機軌跡控制。
- Blender：現有 [預演工具](spatial-previs.md#本機最小工具) 支援固定 lens_mm 與位置／look_at 關鍵點，位置在關鍵點間線性計算並每格烘焙朝向；尚無動態焦距、移焦、速度曲線或連續樣條路徑欄位。不要把上述運鏡卡當作它已支援的新 JSON schema。
- 曲線路徑需要時：在另存工程用 Blender 原生 Follow Path 控位置，獨立目標配 Track To 控朝向。5.2.3 本機依賴圖核對通過 use_fixed_location、offset_factor 及相機 -Z／Y up 組合；這是本機實測，不來自本輪未能取得的手冊正文。目標若接近垂直或轉折大，另查翻轉、roll、穿模與路徑。參數或影格線性不保證沿曲線等距／等速，需量相鄰時間的位置差並看完整播放。
- 精確效果無法由所選路線承載時，先拆成可剪輯的動作／反應鏡，或提供可執行的預演設計。新增模型、下載或雲端服務按實際缺口與使用者授權處理。

## 驗收與修正

先按用途選檢查：機位起中終、跨軸與畫面方向、揭露是否過早、前景遮擋、主體畫面尺寸、眼線與焦點、速度／停頓、接鏡狀態。原速看重要反應，再逐格定位問題；幾張預覽不能替代完整運動驗收。

只比較最高風險變量。運鏡蓋掉表情時，可保留同一表演版本比較固定與移動機位；若要歸因模型設定，另對齊素材、seed 及採樣條件。整體重新生成不能證明差異只來自相機。幾何、動畫預覽、生成影片與最終成片分層回報，只有已接受輸出才能更新 [連續性帳](production.md)。
