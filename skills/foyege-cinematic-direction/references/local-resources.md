# 本機資源與製作路由

## 選擇原則

先從專案已接受素材與可重現的既有工作流挑選。角色、服裝、場景、聲音版本由專案資產表決定。技能示例中的人物與服裝僅供方法示範。開源、可下載與本機已可用是不同狀態。

以任務所需範圍核對下列證據，沿用仍有效的檢查結果。

| 狀態 | 所需證據 | 能支持的結論 |
| --- | --- | --- |
| 檔案已存在 | 絕對路徑、檔名／版本、非零大小，必要時查既有雜湊報告 | 可列為候選資源 |
| 節點可載入 | 運行中 ComfyUI 的節點資訊、啟動日誌或實際載入結果 | 可組工作流，尚待推論 |
| 短測通過 | workflow、輸入、設定、輸出、耗時、VRAM、看片結果 | 指定條件下可執行 |
| 成片已接受 | 正常速度觀看、聲音檢查、接鏡檢查與接受紀錄 | 可作下一鏡承接來源 |

來源教學、磁碟上的節點程式碼與上游展示各自記錄。節點資料夾存在仍可能在啟動時載入失敗。量化、蒸餾、LoRA、文字編碼器與 VAE 必須配對檢查。雙 GPU 的可用顯存按實際工作流分配，不能直接相加當作單卡容量。

## 任務所需的資源盤點

在自己的專案記錄以下欄位；公開套件不預設讀者的模型、工具位置或就緒狀態。歷史配方僅見 [短測摘要](local-tests.md)。

| 用途 | 應核對的入口 | 條件 |
| --- | --- | --- |
| 空間、機位與走位 | Blender 執行檔、本技能 scripts/build_previs.py | 可用 CPU 做幾何預演；臉部 rig 另查 |
| 首圖、角色參考與布局 | 既有圖像模型、參考槽位、權重與工作流 | 按已通過的相容配方選用 |
| 單鏡 I2V | 相容首圖、模型、文字編碼器、VAE | 以實際引用為準，不能只看工作流名稱 |
| 表演轉移 | 已授權驅動片、角色圖、轉移模型及節點 | 微表情和身份另驗；生成驅動與真人驅動分開 |
| 頭像局部校正 | 已有 LivePortrait 或其他相容工具 | 原始碼、權重、環境與節點載入分開核對 |
| 姿態與後製 | 既有姿態工具、FFmpeg、剪輯器與補幀工具 | 驗收原生影格後才比較處理版本 |

只查任務需要的資源與負載，沿用仍有效的日期化紀錄。沒有生成需求時不為盤點啟動模型。資源不足先交付文件及待測路線，不自動切換付費服務。

## 由鏡頭需求選路線

1. 只有提示詞／分鏡需求，直接交付導演卡、模型候選及待綁素材。無須為寫作啟動推論服務。
2. 已有合格首圖、簡單視線或單次反應，先用相容的既有 I2V 工作流做短測。模型候選依接受紀錄排序，沒有紀錄時標記測試路線。
3. 需要保留明確微表情先後或全身節奏，優先評估自攝／已授權的驅動影片配本機 Wan Animate 2。先核對參考表演本身，再確認身份與細節是否被保留。[T5](tutorials.md#t5-wan-animate-2)
4. 只需頭像局部校正，可評估已有 LivePortrait 原始碼的環境缺口。若已具相容模型、環境或節點即復用，否則先列缺件。批次頭像變形需檢查裁切邊緣、牙齒、眼球與大角度側臉。[T7](tutorials.md#t7-liveportrait)
5. 多人站位、跨鏡機位、接觸與遮擋用 Blender 預演。重要臉部表演若有可用骨架／形態鍵，才進一步製作表演參考。代理柱體缺少的臉部資訊仍由實拍參考或導演卡補足。
6. 現有路線失敗，先依失敗層修正首圖、驅動片、構圖、節奏，或拆鏡、局部合成。新增權重／節點／服務需指出補足的能力、下載／磁碟／運算成本及既有授權，並保留可用版本。

## Wan 版本分流

- 本機 `wan_animate2_distilled.json` 對應 **Wan Animate 2**，上游以直接驅動影片為主要入口。照這份工作流核對輸入與量化版本。[T5](tutorials.md#t5-wan-animate-2)
- **Wan2.2 Animate** 官方舊教學以姿態、臉部控制及 Mix／Move 流程示範，適用於對應節點與權重。[T6](tutorials.md#t6-wan22-animate)
- **Wan2.2 I2V／TI2V** 是另一條生成路線。僅有名稱相近或 VAE 共用，仍須核對模型與 conditioning 相容性。

## 每次執行留下的最小紀錄

鏡頭／take ID、所選路線、workflow 檔與版本、實際權重及輸入版本、原始導演卡、最終送入模型的文字、seed、解析度、fps／影格數、採樣設定、輸出路徑、耗時與觀察結果。若工作流有 prompt enhancer，保留改寫結果並檢查它有沒有增加眨眼、微笑、轉頭或音樂。已有專案紀錄格式時直接沿用。

沒有可用的逐幀控制時，時間窗只作導演目標。精確停留、反應前後餘量、音軌同步與切點在本機時間線完成。原生輸出驗收後，再比較補幀、修臉、放大與調色版本，確認微反應仍可讀。
