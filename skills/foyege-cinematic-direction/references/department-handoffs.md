# 美術、攝影、聲音與 VFX 的交接

當鏡頭依賴造型細節、光線、聲音事件或局部合成時讀本頁。只取會影響當鏡的欄位，沿用角色／SET／LOOK／PROP／VOICE 正本及 [製作模板](production.md)。不用在每個提示詞塞進所有部門術語。職能背景見 [T40–T44](tutorials.md#2026-11-09-劇組職能研究)，以下卡片為原創製作適配。

## 美術服化與道具狀態

美術外觀與空間母本分開：平面、尺寸與家具決定路徑；造型、材質與陳設決定可見外觀。角色圖的服裝不能覆蓋當鏡已指定的 LOOK；新增背面、標誌或材質要記明確認／假設／未見。主參考不能每鏡自行換版。

```text
資產／LOOK／PROP ID、版本與來源：
故事日、適用場次及已接受基準：
必須可見：輪廓／比例／色彩／圖案／字／材質
當鏡狀態：手別、持有者、扣位、折痕、濕痕、髮束或妝容
變化事件：由什麼接觸或動作造成；結束時留下什麼
重拍重置與下一鏡承接：
最終相機下的檢查範圍與未見視角：
```

在正面、反打、遠近景中檢查「同一物件與狀態」，不只查色名。文字／徽章需要精確時先評估可編輯字層或局部合成；生成圖片帶字不自動算字層已完成。衣料和反光材質須連同光線看，不能把材質變化全歸為顏色錯誤。

## 攝影燈光與外觀基準

攝影、燈光、美術與調色共用一份可追溯的視覺目標。先寫可見結果與物理光源，再填實際工具有的參數；外觀描述不是燈具、光比或曝光的實測值。

| 項目 | 交接內容 |
| --- | --- |
| 視覺目的 | 當鏡讀點、人物與背景分離、需看見的眼睛／嘴角／手部 |
| 機位 | 路徑、朝向、畫幅與視野；見 [運鏡卡](camera-movement.md#原創運鏡卡) |
| 光源母本 | 世界位置／方向、可見燈／窗及時段；換機位後推導畫面方向 |
| 光質與材質 | 軟硬、明暗層次、反光／陰影；輪廓與膚色／角色色的保持 |
| 焦點 | 哪個距離／目標必須清楚、移焦時序及表演可見區間 |
| 外觀參考 | 來源版本、適用光況、顯示方式與已套用處理 |
| 量測與限制 | 真的量了什麼、使用工具與範圍；未知白平衡／色彩標記另列 |

正反打維持世界光源；故事要求換光、舞台閃光或夢境變化時可另立事件，不把連續性誤解為全片不准變。暗部氣氛不能讓必要表情不可讀；有意剪影依敘事判斷，不能當成已看清臉。

技術色彩解讀與創作 look 分開。記錄已知輸入色彩、工作／顯示處理及輸出；不知道就先保留未知，不為風格直接改標 log、HDR 或 BT.709。審片套用的 look／LUT 是否已烘焙要查明，避免回交再套一次。生成圖沒有相機原始 RAW 的可調空間保證，剪切的高光或不存在的材質細節不能靠換位元格式恢復。

需要穩定精確光向時可用既有 Blender／場景工具驗布局及遮擋；本頁不宣稱現有預演腳本已實作燈光設計、色彩校準、焦點或完整 look-dev 控制。實拍用色卡／監看或調色套件的量測，與生成影像的目視比對分別記錄。

要整理同組正反打的世界光源、色彩解讀、觀看條件與已烘焙 look 時，用 [光色交接準備與 CLI](sync-and-look.md)。未知欄保留 null，重複 look 或基準差異列待審；工具只核對聲明，不量測／改寫像素。

## 聲音事件與前期責任

沿用鎖定歌曲與已接受對白，不以補音效改動演唱。聲音前期就綁敘事事件；後期響度、PCM、字幕與聽審方法沿用 [聲音交接](media-handoff.md#聲音主檔測量與聽審分開)。

```text
聲音 cue ID → 場次／shot → 誰或什麼發聲
用途：對白／歌／心聲／畫外聲／環境／接觸／音樂
來源版本、是否已取得、允許使用的範圍：
觸發：詞／可見事件／音軌位置；音軌未到則標暫定
同步責任：口型、手部接觸、畫外反應或不需逐格同步
空間：畫內／畫外、方向、距離與場景混響意圖
取得方式：原素材／錄音／已授權生成／Foley／ADR／後補
前後保持／尾音與交接：誰製作、誰聽審、交回哪版
```

有聲源不代表必須同時露出發聲者；沒有口部表演也不等於無聲。實拍錄音若有衣物摩擦、環境噪聲或無法收錄的台詞，記實際問題與補錄責任，不直接寫「後製會修好」。AI 影片未產生可用聲音時標缺口，不用 ASR、靜音軌或模型回傳成功當聽審。沒有 stems 不假造分軌；音樂創作已結束時不重走作曲流程。

## VFX 與動畫先確認交得出什麼

先按鏡頭判斷：全畫面生成、局部修補、2D 合成、3D／動畫，或幾者混用。VFX 在前期確認可取得的素材，不等整段生成後才發現缺手、缺背景或無法對齊相機。圖片參考、深度／mask、骨架與可編輯表情 rig 的責任分開；SAM3D、RefMod 或 GLB 的存在不等於已完成角色轉接或合成。

```text
shot／剪輯版本與實際 source in/out、timeline in/out：
要增加／替換／保留的元素及完成判準：
來源畫面與版本：乾淨底圖、前景、遮擋、mask／alpha（有才列）
相機／鏡頭／尺度或追蹤資料：已知值、估計值與未取得項
動作／角色資產：骨架、表情控制、材質及對應版本
fps、解析度、影格起算、餘量、色彩／alpha 解讀：
工作預覽、乾淨返回檔與可編輯依賴：
回交檢查者、接點及需要重查的下游：
```

clean plate 只在需要分離背景或合成時準備；全畫面生成不強制拍全部輔助素材。沒有 alpha 的輸出不能假稱已分層。實際需要 matte／深度／反射或追蹤時核對工具輸出和資料定義，不能因節點同名就混用。逐格查邊緣／遮擋、接觸陰影、反射、動態模糊與顆粒，先前景與背景的時間／相機相容，再談風格匹配。

修臉、補幀或升檔後，重看眼皮、瞳孔、嘴角與手部事件及接鏡；漂亮的靜態畫面不能覆蓋動作失敗。母版或調色版回交後可能已改變材質與表演可讀性，需在同一顯示基準比較。

## 返回品管的最小證據

每項只交「原要求／基準 → 實際素材版本與範圍 → 可見或可聽結果 → 通過／需修正／未檢查 → 接收者與下一步」。幾何、角色外觀、光色、聲音、合成與最終播放各自記錄；不能拿某一部門的通過替代整鏡接受。部門衝突回到該鏡敘事用途與已鎖定正本，沿用原權限，不因本頁增加每步確認。
