# 微表演設計

## 來源與用途

作者在白模教學約 09:00 直接展示嘴角鬆動、一次輕微下巴顫動、眼睛先移開、頭隨後轉開並稍低、新淚沿既有濕痕下滑的順序。他強調可見的洩漏、壓制、失敗與殘留。下列工作卡與診斷法是本技能對該方法的操作化延伸。[S4](sources.md)

「微表演」在此指克制、細小且具時間關係的影像表演。不要把它包裝成測謊、讀心或普遍固定的情緒肌肉公式。具體心理是虛構角色的導演設定，觀看真實人物時只描述可見訊號。

## 表演卡

為需要細膩表演的鏡頭填寫，簡單鏡頭可縮成一段。

| 欄位 | 決策 |
| --- | --- |
| 刺激 | 哪個字、物件、視線、聲響或接觸觸發改變 |
| 當下目的 | 角色想讓對方相信什麼，或想取得／避免什麼 |
| 台詞目的 | 說給誰聽，這句是在試探、安撫、敷衍、拒絕或爭取什麼 |
| 基準與變化 | 相對該角色起始表情，哪個部位改變、哪個保持，幅度在本景別是否可讀 |
| 壓制方式 | 維持眼神、勉強笑、固定下顎、繼續手中工作等 |
| 可見洩漏 | 選一個主要變化，最多搭配少量有因果的副反應 |
| 先後關係 | 眼神、頭、嘴與呼吸誰先動，哪個保持 |
| 收回與殘留 | 如何恢復表面控制，何處仍留下上一拍 |
| 視線目標 | 對方哪個部位、具名道具或畫外座標 |
| 可見條件 | 景別、角度、焦點、臉部光線、遮擋與停留時間 |
| 起終狀態 | 下一鏡能承接的眼神、頭向、姿勢、濕痕、呼吸 |

不必每拍都讓全臉動。先選觀眾必須讀到的一個變化，再加會幫助理解的細節。明顯顫抖、頻繁眨眼、大幅挑眉容易把克制表演推成誇張反應。

台詞目的可參考 [R1](related-skills.md#r1-中文表情演繹)。同一句「我願意」可設計為安撫對方或勉強應允，先選當下關係目的，再決定聲音與動作。已鎖定的歌曲以實際唱法為準，表演卡將口部動作安排到可用間隙。

台詞觸發細分、打斷與未完成發聲，按需讀 [詞級觸發與話輪](acting-beats.md)。該頁補充保持條件、聽者反應與聲音驗收，沿用本頁的表演卡。

## 時序設計

使用相對事件順序建立因果，再按片長給寬鬆時間窗。先「聽到關鍵詞」，後「視線停住」，再「試圖恢復」。避免把眨眼、眼眶變紅、流淚、吞嚥、微笑、轉頭塞在同一瞬間。

時間窗、角度和幅度是導演目標。作者例中的 20–30 度僅屬該鏡頭。模型沒有已證實的逐肌肉控制能力時，使用自然語言與可見結果，不發明 FACS 參數或精度保證。

對白期間讓嘴完成字音。嘴角壓回、抿唇、吞嚥等可放在台詞前、停頓或尾音後。連續歌唱鏡頭同理，讓眼神與呼吸間隙承擔情緒。

## 原創可用示例

情境為成年修復師林岑收到失蹤搭檔的鑰匙。她想讓送信人相信自己早已放下。8 秒反應特寫，角色圖待綁定，以下為新的導演設計。

> 固定四分之三側面近特寫，眼睛保持清晰，柔和側光照到近側眼與嘴角。林岑起初望著畫外右方送信人的雙眼，嘴角維持極淺的禮貌弧度。前兩秒，送信人的手在畫面下緣放下舊鑰匙，她的目光先落到鑰匙，頭仍保持原位。約第二至四秒，原本上提的嘴角慢慢鬆開，下顎短暫收緊，她吸氣到一半停住。約第四至六秒，她把視線重新抬回送信人的雙眼，試著恢復先前的微笑，但只回到更淡的一點弧度。最後兩秒，緩慢吐氣，肩膀幾乎不動，眼神留在對方，手指仍停在鑰匙旁而未碰它。保持同一張臉與既有服裝，鏡頭持續停留到反應結束。聲音為鑰匙落桌與克制呼吸，音樂依專案設定另行混音。

若台詞是「我早就不在意了」，把它安排在抬回視線後，並將恢復微笑延至尾音後。8 秒容納不下時拆鏡或延長，先保留因果與可讀停頓。

## 其他情緒的原創改編

- 隱藏喜悅。聽見好消息後目光短暫抬起，一側嘴角先上揚，發現對方注視後將嘴角收回，最後仍留較亮的視線。依角色習慣調整，避免套成所有人的固定反應。
- 克制敵意。眼睛持續追蹤對方持物的手，下顎稍收緊，回答前吐出一口短氣，頭保持穩定。危險移動時才帶動肩與腳。
- 逞強後受傷。先完成防禦動作，接觸後呼吸中斷，手指重新握緊，短暫看傷處，再把目光拉回對手。後續鏡頭保留喘息與受傷限制。
- 假裝無事。維持原本工作節奏，聽到名字後手停半拍，視線仍留在工作上，下一拍刻意接續，手勢比先前更小。可用手部和聲音承擔遠景看不見的臉部變化。

## 檢查與修正

| 可見失敗 | 優先修正 |
| --- | --- |
| 只有僵臉 | 加明確刺激與單一狀態改變，保留反應時間 |
| 全臉忙碌、像表情包 | 減少同時事件，降低幅度，保留原來姿勢 |
| 眼神游移 | 明確命名唯一目標，寫清切換發生在哪個刺激後 |
| 眼和頭機械同步 | 明寫目光先移，頭暫停，再跟隨 |
| 表情寫得細卻看不到 | 調景別、焦點、遮擋或曝光，再測表演 |
| 每鏡都重新哭 | 從上一鏡淚痕、呼吸、眼眶狀態續接 |
| 說話時嘴不自然 | 錯開發音與抿唇、咬唇、吞嚥動作 |
| 換臉或五官漂移 | 回查角色素材、角度與身份綁定，暫減複雜動作 |

看片先以正常速度檢查是否讀得懂，再逐幀定位先後和漂移。抽幀只能支持取樣點的觀察，不能證明短暫動作的完整時間順序。對演員可使用人物目的作指導，對生成模型另外給可見身體結果。


## 補充表演控制

以下將 T1／T2 的表演教材整理為可檢查欄位，拍攝及測試設計為本技能延伸。[教學依據](tutorials.md)

- **處理停頓**。刺激抵達後，留出角色接收資訊的時間，再讓主要變化發生。可先短暫停止原有動作。停頓長度由鏡頭節奏決定。
- **眨眼目的**。每個刻意安排的眨眼註明觸發與用途，例如收回注視或恢復社交姿態。選擇持續注視時，也保留呼吸及局部張力變化。
- **眼線驗收**。記錄具名目標與切換條件，以最終攝影機判斷是否看向該目標。兩次目光移動間保留可讀的聚焦停留。
- **反應錯峰**。關鍵表情發生時降低大幅身體運動或運鏡的競爭，讓重要變化先被看見。突然接觸等情況依物理反應決定先後。
- **殘留**。恢復表面表情後，選一處保留前一狀態。連續歌唱時優先讓眼瞼、視線或手指承擔殘留，嘴部按原音軌發音。

### 可拍攝的參考表演卡

需要比文字更穩定的時序時，沿用已授權素材，或準備自攝表演。先把鏡頭縮成「起始保持 → 刺激 → 一次主要變化 → 恢復與尾端保持」。記錄刺激點、視線目標、臉與頭先後、音軌 offset 與供剪輯的前後餘量。

拍攝眼睛、嘴角與下顎可讀的近景，照明與曝光穩定，避免遮住主要反應。表演幅度按成片需求，錄製少量可比較版本。先正常速度檢查原始表演是否成立，再投入轉移。LivePortrait 路線按其頭部裁切與起始姿態建議準備；Wan Animate 2 的全身動作路線保留身體和接觸物件。[T7](tutorials.md#t7-liveportrait) [T5](tutorials.md#t5-wan-animate-2)

### C1 的克制反應測試卡

原創測試情境為「聽見再次要求微笑」，角色造型與音軌以專案接受版本綁定。可先測六秒非歌唱反應，時長依選定模型支援值調整。

| 階段 | 可見事件 | 保留狀態 |
| --- | --- | --- |
| 開始 | 注視畫外主人，已有禮貌淺笑 | 頭與肩穩定 |
| 刺激 | 畫外說出「再微笑」，視線在主人眼睛停住 | 嘴角維持原弧度，給接收資訊的停頓 |
| 洩漏 | 笑意先退去一點，短暫吐氣 | 仍看著主人 |
| 收回 | 嘴角恢復到更淡的弧度 | 眼瞼保持前一拍的疲態 |
| 尾端 | 目光轉向鏡頭後停住 | 頭延後小幅跟隨，留出接鏡餘量 |

先測「目光先移、頭後跟」或「嘴角恢復、眼瞼殘留」其中一項。採用哪項取決於該鏡最重要的資訊。記錄刺激是否先於反應、目標是否明確、轉變是否可讀、身份是否穩定。這張完整表演卡的精確時序與觀眾可讀性仍待驗證。相關的開眼淺笑已完成本機單案例短測，見 [結果與限制](local-tests.md)。

本機 Wan2.2 5B 短測曾在「保留疲態」時自行閉眼。需要持續注視時，把它寫成可見的眼瞼高度、唯一目標和保持條件，再逐幀檢查。眼睛、嘴角與頭部各自驗收。模型只有整體轉頭時，需增加可讀的中間狀態、調整片長，或改用有合格表演參考的控制路線。

### 表情狀態與分區驗收

當角色表情難以對齊時，先用既有合格素材建立少量狀態，可從「起始、主要變化、收回後殘留」開始。每個狀態保留相同角色版本與可比較視角，寫出相對基準的局部差異。需要補圖時列入後續生成計畫。此表為本技能結合 [R4](related-skills.md#r4-局部臉部動作與表情參考) 與 [R5](related-skills.md#r5-人物微表情分鏡) 的本機適配。

| 分區 | 可檢查的描述 | 該鏡證據 |
| --- | --- | --- |
| 目光 | 注視哪個目標，何時開始移動及停住 | 原生影格／時間點 |
| 眼瞼與眉 | 相對起始的高度、張力與眨眼事件 | 改變、保持或不可辨 |
| 嘴角與下顎 | 嘴角弧度、閉合程度、下顎動作與音節關係 | 改變、保持或不可辨 |
| 頭頸與呼吸 | 開始轉向、停止位置、吸吐氣的可見線索 | 與目光／台詞的先後 |
| 身份 | 臉型、眼色、標誌與造型是否符合資產版本 | 接受依據或偏差 |

表情圖可標「弱／中／強」作同一角色與景別內的比較，配上具體可見差異。AU 僅在有可靠定義時作輔助註記。使用 Blender 或臉部控制節點時，先記錄實際骨架／形態鍵名稱、值域與可見效果，建立資產專用映射。

驗證「眼先頭後」時，逐幀定位目光首次明顯位移、目光穩定、頭部首次明顯轉動及終態。固定 fps 片段以 `(頭動影格 - 眼動影格) / fps` 記錄可觀察延遲，變動 fps 使用各幀時間戳。模糊、遮擋或兩者同一格才可辨時，標記精度不足，再以原速檢查觀眾能否讀到先後。不同角色或鏡頭的可讀延遲需個別設計。

表情峰值只代表那一刻的形態。I2V 起始幀依本鏡開始位置選擇，從平靜開始就用反應前狀態，延續中途表演就承接已接受的當下狀態。完整多格表情表供人工比對，傳入模型的單格及輸入角色按 [參考圖職責](spatial-previs.md#參考圖職責) 綁定。


### 目光與情緒承接

一次視線切換寫成「原目標 → 刺激 → 新目標 → 聚焦停留」，把快速移動與停住分開檢查。眼瞼、眉與頭部需要錯峰時依參考設計；純文字生成仍只交可見事件，不聲稱逐部位控制。維持注視的鏡頭不需補眼球抖動。[T9](tutorials.md#t9-目光切換與局部錯峰)

同一情緒在剛發生、尚在處理與稍後回想時，可有不同的呼吸、語句和行動。跨鏡承接依故事經過時間及已接受 take 決定，不能因換鏡就重演刺激。寫清角色此刻仍要完成的事，不只標情緒強度。[T12](tutorials.md#t12-情緒距離與可演行動)

原創設計例：C1 收到消息後仍整理收據。上一鏡已讀完消息，下一鏡承接手停在最後一張收據上；她試著把邊緣對齊，第一次未對正，再小幅修正。目光留在紙邊，表情與呼吸不回到「剛收到消息」。這是待拍／待生成方案，不是既有短測結果。

### 後製保護

保留原生 fps 版本，逐項比較補幀、修臉及放大後的版本。若慢眨眼被拉成拖影、嘴角微動被平滑掉、瞳孔漂移或牙齒閃爍，回到對應階段修正。檢查原速、近景局部與剪接前後，避免只憑單張修得漂亮就接受整段。
