# 製作、提示詞與連續性

## 可貼用模板

按模型能力將下列內容編成流暢提示詞。專案資料與待綁定欄位要在交付時明確分開。沒有獨立負面提示欄時，將必要約束改寫為正向可見狀態放入主文，例如固定機位、閉唇停留。負面提示欄是否存在及是否有效按模型核對。

```text
鏡頭 ID／用途／目標時長／畫幅
本鏡頭讓觀眾得知的事，以及角色當下目的

素材綁定
角色 ID → 實際檔名／版本 → 外觀、服裝
場景 ID → 實際檔名／版本 → 材質、光色
預演 ID → 實際檔名／版本 → 機位、構圖、走位、時序
道具 ID → 實際檔名／版本 → 持有者與可見特徵

起始狀態
人物位置、朝向、視線、持物、接觸、呼吸與既有傷痕／濕痕
鏡頭景別、角度、焦點、運動、可見前景與背景

時間窗
刺激 → 可見動作 → 接觸或局部反應 → 恢復與殘留
每窗只補當前鏡頭新增的變化

聲音
對白原文與說話者、呼吸、接觸聲、環境、音樂／節拍來源

結束狀態與接鏡
眼神目標、頭向、動作進度、持物與情緒殘留
需要的剪接餘量

必要約束與驗收
本鏡頭必須維持的身份、拓撲、因果和可見節拍
```

輸出還要附一小段執行對照，列實際模型／介面、支援的輸入槽、時長與畫幅選項、尚缺素材及可測項目。模型未知時保留中立模板，避免假定所有服務都接受影片、音訊或多張角色參考。

借用表演參考、多視角資料或大幅運鏡時，另用 [事件對照與分層驗收](performance-transfer.md#表演機位與生成分開驗收) 綁角色目標、機位時間線、實際捕捉範圍及輸出事件。中間預演有使用才列入，不為填表啟動新流程。

需移動相機、變焦或移焦時，用 [運鏡卡](camera-movement.md#原創運鏡卡) 指定用途、起動、路徑、落定、表情可見區間與接鏡。將文字意圖與實際控制分開；不要把推軌、變焦、移焦當作同一動作。

## 按作品形式調整

### MV

使用指定音軌版本、起始 offset、拍速／變速段、歌詞或節拍標記。未取得音軌時以暫定段落標記工作，精確卡點留待音軌到位。不要把作者某個無 BGM 範例擴成 MV 的要求。

將大動作、換景與剪接放在需要強調的拍點。細膩反應可跨拍完成，保留延遲與停頓。歌唱嘴型與抿嘴／吞嚥錯開。舞蹈參考若控制動作與隊形，另寫角色與服裝替換範圍，保留足部接地、隊形身份與接觸。最後在剪輯時間線校對卡點，生成時間碼需視結果微調。

### 短劇與對話

按人物目的與資訊揭露分鏡。反應鏡頭要有可追溯的刺激，注意畫外說話者、聆聽姿態、眼線與台詞尾音。預留反應完成後的剪接空間。簡單雙人談話先用角色圖、場景圖和眼線說明，複雜越肩、換位或跨軸再引入預演。

需要搶話、說不出口或詞級表情變化時，使用 [話輪與觸發卡](acting-beats.md#話輪誰在說誰準備進入)。先選等待、打斷或沉默，再按實際聲音控制能力編譯；鎖定的 MV 主音軌保留原詞與唱法。

### 長劇／系列

使用 episode-scene-shot-take ID。共用角色外觀與場景版本，每個 take 保留生成設定和實際使用的素材。情緒、知情狀態、傷勢、衣物、道具、手別、日夜、軸線與聲音承接進入連續性帳。

| shot/take | 階段 | 承接來源與證據 | 資產版本 | 入鏡狀態 | 觸發與改變 | 出鏡狀態 | 接下一鏡 | 審核證據 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| E01-S03-010/T01 | 計畫 | 上一已接受 take ID 與尾幀檔 | C1v2 SET1v1 | 右手持鑰匙，呼吸急 | 聽到否認，握緊鑰匙 | 仍持鑰匙，視線轉門口 | 020門口反打 | 待看片 |

區分「計畫」和「已接受輸出」。新鏡只能承接已接受的狀態，或明確標記待生成依賴。跨集更新角色資料時留版本，防止舊鏡被新設定覆蓋。單鏡生成失敗只回滾該 take 的暫定變化。

### 廣告、動畫、其他影像

沿用刺激、表演、空間、因果與接鏡結構。依媒材調整誇張程度、材質和視覺節奏。產品鏡頭優先鎖定形狀與標識，角色動畫可用姿勢和停格節拍呈現微反應。不要自動套成真人電影風格。

多鏡場景在生成與剪輯前，用 [事件覆蓋表](scene-coverage.md#檢查必需事件有沒有鏡頭承擔) 核對必要動作、原句、畫外聲及反應各由哪個可用區間承擔。補鏡保留可比對的重疊動作，劇本改動後重查受影響的揭露與承接。

## 短測與診斷

先確認使用者授權的生成工具與成本範圍。純提示詞請求交付草案即可。執行測試時，從目前最大不確定性選一個檢查。

- 身份／空間風險高。以短片確認人數、身份、家具、站位、眼線與軸線，時間依模型可用選項決定。
- 微表演風險高。近景保留刺激和一次反應，先驗證目光目標、先後與幅度。
- 動作風險高。只測一次接觸，確認發力、命中、反作用、支撐腳與殘留。
- 鏡頭風險高。先看白模預演，檢查構圖、遮擋、速度、穿模與越軸，再送生成。

若沒有既定預算，提出小規模候選數與停止條件，在需要付費或提交外部生成時遵循當前授權。每輪只改對應層，保留版本比較。連續兩輪未改善可回到輸入素材／拆鏡判斷，避免無限加形容詞。

驗收採「通過／需修正／未檢查」，列時間碼和具體可見證據。視覺抽幀、連續播放、字幕閱讀、ASR、音訊聽審分別記錄。對白是否可懂、音樂接縫與呼吸自然度需要實際聽審。禁止以可解碼或音訊波形正常宣稱內容正確。

## 跨部門製作

多鏡製作的前置依賴、資源順序、場記重置與改稿影響，按需使用 [跨部門製作](crew-workflow.md)。當鏡依賴美術服化、光線、聲音事件或局部合成時，用 [部門交接卡](department-handoffs.md) 補齊責任與可用素材；已有 film-production 時沿用其鏡頭卡，不新增重複正本。

## 剪輯與交付周邊

收素材、建立代理、跨軟體交接、混音、字幕或輸出時，按需讀 [素材、剪輯交接與成片驗收](media-handoff.md)。它處理來源版本、時間映射、字幕／音軌與交付 profile；純提示詞或劇本不要求填整套清單。

## 最小交付

單鏡請交提示詞、素材綁定和關鍵待驗證項目。跨鏡作品另附分鏡及狀態帳。若已生成或實拍，附可播放成品和檢查結論。來源研究、工具能力與成片品質各自保留證據邊界。


## 導演卡轉成模型提示詞

導演卡保存意圖、節奏、資產與接鏡責任，執行提示詞只攜帶該模型能處理的內容。先依 [本機資源](local-resources.md) 選定候選工作流，將資產與控制訊號送入對應槽位。

| 模型／媒材 | 編譯方式 | 需要核對 |
| --- | --- | --- |
| 既有 I2V | 首圖負責已可見外觀，文字寫下一個動作、鏡頭和收尾 | 首圖與指定起始表情是否一致 |
| 本機 LTX-2.3 | 用連貫段落描述足以填滿本鏡的可見變化，說話分短句與停頓，保留必要聲音設計 | 與片長相稱的細節、實際音訊入口與提示詞改寫結果 |
| Wan Animate 2 | 角色圖綁外觀，驅動片綁表演，文字補工作流支援的視角與場景要求 | 驅動片本身的節奏、身份漂移、文字是否與動作衝突 |
| LivePortrait 候選 | 先核對環境、來源頭像及驅動素材，再用已暴露的眼嘴／表情控制 | 起始姿態、裁切、大角度、合成邊緣 |
| Blender 臉部動畫 | 導演節拍映射到已存在的骨架／形態鍵，從目標相機檢查 | 骨架可用性、眼瞼接觸、曲線過衝與嘴型衝突 |
| 使用者指定 Runway Gen-4 | 簡潔正向動作描述，先一個主要變化，再逐項增補 | Gen-4 該版輸入與時長，外部生成授權 |

版本依據見 [T3–T7](tutorials.md)。模型未明時交中立導演卡，已存在的 MOSS 首圖、H3 或其他候選依其本機配方處理。不要把某模型的步數、負面提示或影片輸入套到另一模型。

以原創「勉強恢復微笑」示範同一卡的兩種編譯寫法。兩者均為完整反應鏈的未生成草案，角色首圖、足以容納節奏的實際時長與工作流另綁定。首輪短測只選嘴角變化或眼頭先後其中一項，完整段落可依 [兩鏡交接草案](#c1-的兩鏡交接草案) 拆開。

**簡潔 I2V 動作稿**

> 固定近景。她望著畫外右方的人，聽完後停了一拍，嘴角的淺笑鬆開。她短暫吐氣，重新露出很淡的微笑，眼睛保持起始開度，視線停在對方雙眼。目光先轉向鏡頭，頭稍後跟隨，最後停住。

**LTX-2.3 節奏較完整稿**

> 固定近景承接首圖，她起初看著畫外右方的人，維持很淡的禮貌微笑。聽見畫外說出的「再微笑」後，她仍看著對方，留出一拍接收這句話，嘴角的弧度才慢慢鬆開。短暫吐氣後，她把嘴角恢復到較淡的微笑，眼睛保持起始開度，視線仍停在對方雙眼。她的目光先轉向鏡頭，頭稍後小幅跟隨，肩膀保持穩定，結尾停留供剪接。畫外台詞與呼吸依鏡頭音訊路由製作。

主音軌已固定的 MV，先標記歌唱／對白／反應／畫外音鏡頭。只有確認支援所需音訊條件的工作流才負責同步，其他素材在剪輯時間線綁定。保留歌曲主檔，模型新生成聲音按實際用途分軌處理。

## 反應與接鏡卡

跨鏡接續時加上下列欄位，簡單鏡頭可併入現有狀態帳。

| 欄位 | 內容 |
| --- | --- |
| 聲音刺激 | 來源音軌／版本、關鍵字或音效位置、接收者 |
| 表演可讀段 | 刺激、處理停頓、主要變化、殘留各自落在哪一鏡 |
| 視線與畫面位置 | 出鏡目標、入鏡目標、畫面左右與注意力落點 |
| 切點理由 | 訊息已讀到、動作承接、反應被打斷或音樂段落改變 |
| 聲畫關係 | 同切、下一鏡聲音先入的 J-cut、前鏡聲音延續的 L-cut |
| 剪輯餘量 | 所需入／出把手，按秒或影格與 fps 記錄 |

例如先見 C2 說話，再切 C1 聆聽，讓 C2 的後半句持續覆蓋 C1 的反應，採 L-cut。若 C1 仍在原畫面，下一場的啟動聲先進入才切新畫面，採 J-cut。定義依 [T8](tutorials.md#t8-聲畫錯位剪接)，場景選擇為本技能設計。

把手可先提出前後各 0.5–1 秒的剪輯目標，依音軌、模型片長及反應速度調整。真正重要的微反應需要保留連續可讀區間。刻意中斷時記錄敘事目的與下一鏡留下的後果。眨眼可作候選切點，最終按觀眾是否讀到反應決定。

## 成對接鏡與保留區間

這是依 [R2](related-skills.md#r2-導演分鏡與剪接) 改寫的本機交接卡。先確認兩段是同機位延長、換機位反打，或跨場蒙太奇。換機位時使用同一世界狀態重建 B 的構圖，A 尾幀可供狀態參考。直接把 A 尾幀送入 B 首幀槽，僅適用於確實要延續該構圖且模型支援的路線。

| 項目 | A 的有效尾端 | B 的有效開頭 |
| --- | --- | --- |
| 依據 | 已接受 take 與實際切出影格 | 已接受 take 或待生成首圖 |
| 人物與空間 | 角色／造型版本、持物、世界位置與視線目標 | 承接狀態及新機位所見左右 |
| 表演階段 | 反應做到哪裡，留下哪個局部張力 | 接續或轉移注意力的可見事件 |
| 動作與光線 | 移動方向、進度、照明狀態 | 需要連續或有意改變的部分 |
| 聲音與餘量 | 主音軌時間點、有效切出範圍 | 同步點、有效切入範圍 |

為關鍵反應標記「最早可切入、最晚必須保留、允許切出區間」，時間點以看片及實際音軌落位。表演被分散到多鏡時標明每段由誰承擔。頭尾品質逐段檢查，保留有用停頓。局部身份、手別或空間失誤先追查參考及機位，再判斷局部修正、改切點或重做。

### C1 的兩鏡交接草案

角色 C1 採專案接受的角色／造型版本，檔名及音軌均待綁定。以下為非歌唱反應設計。

- A 鏡，C1 近景。畫外指令「再微笑」結束後，目光停在主人臉上，嘴角先微微鬆開，再恢復較淡弧度。眼睛維持起始開度。保留嘴角恢復後的短暫停留，再決定切點。
- B 鏡，換角度近景。承接 A 的淡笑與目光目標，讓目光轉向鏡頭後停住，頭稍後小幅跟隨。以 B 機位檢查眼線，結尾保留同一表情。
- A 承擔「收到要求與收回反應」，B 承擔「目光轉向觀眾」。先以分區表驗收兩項，再順播檢查是否重演整段反應。若原歌正在持續發聲，改依該段嘴型安排表演或使用聆聽插鏡。
- A 的開眼淺笑可參照既有短測設計，B 的精確眼頭延遲仍待實測。專案身份與音軌綁定完成前維持草稿狀態。


## 注意力與受力檢查

角色眼線回答「角色在看誰」，觀眾注意力回答「觀眾現在應看哪裡」。快速接鏡時記下 A 最後要讀到的重點與 B 第一個重點；可暫時疊合切點畫面比對位置、時機或構圖，檢查後還原實際剪法。刻意轉移注意力時，以動作、聲音或停留引導，不把所有鏡頭強制置中。[T11](tutorials.md#t11-剪接注意力落點)

疊合只作診斷，不能用淡化掩蓋未通過的身份、持物或微反應接縫。調整構圖後重查世界左右、手別、字樣與裁切，避免為對齊落點直接水平翻轉。無素材時標「預定落點」，有成片才記「觀察到的落點」。本段的狀態標記及檢查欄位是本技能延伸。

受力片段另查「接觸前 → 接觸中 → 離開後」的速度與阻力是否可讀，握持點是否滑動、支撐是否消失。重物不只把整段播放放慢；其身體補償、停下及恢復也要對應重量。將偏差定位到相鄰影格及具名接觸點，再修動作或預演。[T10](tutorials.md#t10-重量阻力與接觸)

## 外觀質感與觀看條件

角色素材先選與成片風格、景別相容的基準。需要寫實皮膚時，按部位、光線與角色設定選少量可讀細節；動畫或偶像風格沿用已定美術，不自動添加毛孔、瑕疵或年齡痕跡。臉型、標誌與服裝先由資產維持，影片稿描述其後表演與光線變化，避免每鏡重新定義外貌。[Y7](sources.md#y7-角色皮膚與外觀錨點)

驗收同一角色的近景與較寬景，再順播相鄰片段，檢查皮膚是否爬動、突然磨平、濕痕重置或高光閃變。畫面放大銳利不代表微動作自然，單張取樣不能證明動態穩定。

比對候選時記錄來源編碼／標籤、已烘焙的 look、觀看變換與輸出條件；未知欄保留未知。同一觀看條件下比較原生片與後製片，先排除轉換或重複 LUT 造成的膚色差，再決定是否重生素材。[T18](tutorials.md#t18-色彩處理歷史) 的原則用於追溯，不強制改用 ACES，也不把「電影感」當 Log／ACES 標籤。

## 本機短測紀錄

先保留基準素材與最終提示詞。一般以基準一份、只改一個因素的候選一份開始，已有專案候選數與預算時沿用。比較時盡量維持輸入、seed 與其他設定一致，並記錄不可控制的差異。

| 項目 | 驗收方式 |
| --- | --- |
| 刺激與先後 | 正常速度可讀，逐幀定位主要事件，註明實際時間碼 |
| 眼神／幅度 | 目標清楚，主反應在預期景別可見 |
| 身份／形態 | 五官、眼色、痣、服裝與牙齒等依角色規格核對 |
| 接鏡 | 與上一接受 take 並排或順播，核對終態／起態及聲畫 |
| 後製影響 | 原生片與處理後片同速比較，確認微動作和音軌同步 |

只降低可支援的解析度／影格數時，仍要保留眼部像素、完整反應鏈與尾端停留。短測條件不足以看清微表情時標記未檢查。無提升時依失敗層換輸入或拆鏡，避免反覆疊加描述。
