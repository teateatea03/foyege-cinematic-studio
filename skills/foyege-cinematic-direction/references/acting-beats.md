# 詞級觸發、話輪與克制反應

用於台詞牽動表情、打斷、欲言又止與跨鏡情緒接續。依 Foyege 頻道教學 [Y1–Y3](sources.md#2026-11-08-youtube-補充) 整理；以下工作卡及例子為本技能原創適配。教學展示的是導演意圖，未證明本機模型能逐詞、逐肌肉或精確按秒執行。

## 分開保存意圖與執行稿

Y1 將提示分為全局、鏡頭時間軸與表演控制。全局保存資產版本、空間基準、聲畫風格；時間軸交代當前觀察誰及切換理由；表演層寫人物目的、刺激、可見變化及終態。對話需要時另列角色聲線與潛台詞，避免每一拍重寫整間房間、人物外觀與全部風格。

導演卡可完整，模型稿按 [製作與模板](production.md#導演卡轉成模型提示詞) 編譯。AU 只有可靠定義時作自然語言的輔助標記。保持條件及禁止提前發生的反應屬導演限制，實際負面提示欄、聲音控制與參考槽位需逐項核對。

## 把情緒綁到具體事件

先回答四件事：人物為什麼這樣做、什麼事件觸發、觀眾看見什麼、哪個反應要留到後面。需要細節時用八維核對：時間段、人物目的、情緒變化、台詞觸發詞、局部臉部動作、目光與身體、聲音與呼吸停頓、結束狀態與禁止反應。[Y1](sources.md#y1-演技與八維公式)

| 一拍需要的決策 | 可檢查內容 |
| --- | --- |
| 起始與目的 | 從上一已接受鏡頭承接什麼，想讓誰相信或做什麼 |
| 觸發 | 說話者、原句中的確切詞，或具名物件／聲音／接觸 |
| 變化與保持 | 哪一區先變、何時達峰及退去；哪些姿態或局部表情保持 |
| 壓制與殘留 | 用什麼動作恢復控制，收回後哪一處仍留下張力 |
| 聲音與終態 | 是否仍在發音、停頓或換氣；下一鏡承接什麼 |

時間碼綁定來源檔／音軌版本、起點 offset 與適用 fps。教學時間、示例成片時間、專案生成時間線各自記錄；改剪後重新定位觸發詞。沒有音軌時先用事件順序與暫定時間窗，不照搬作者示例的秒數。

## 話輪：誰在說，誰準備進入

對話先決定當下話語權、接話企圖、搶入點及最後誰退讓。打斷可由角色無法接受的某個詞觸發；需要消化資訊時可保留沉默。是否搶話取決於該場人物目的，不把所有對話都改成重疊。[Y2](sources.md#y2-對話停頓與搶話)

在既有表演卡加一行即可：

```text
音軌版本／段落：待綁定
主說話者／目的：C2，要求對方承認事實
原句／觸發詞：……「同意」……
C1的接話：聽見「同意」才準備進入；打斷／等待／改口擇一
可見反應：嘴角先收住；視線仍在C2，頭保持
聲音：哪個詞被截斷、是否重疊、誰退讓；依實際音軌落位
聽者持續反應：搶入失敗後仍看對方，手指未恢復原動作
尾端與接鏡：留下的張力、濕痕、目標與未完成動作
```

要求重疊時指明可懂度與話語權，不硬套教學中的毫秒數。沒有原生音訊或逐詞控制時，先做表演參考／對白音軌，再依可用工作流製作；可用聽者反應鏡配聲畫錯位剪接。雙人聲音重疊不代表兩張臉必須同框，也不代表必須讓兩個嘴同時可見。

## 說不出口必須有身體過程

將未完成發聲設計為角色在特定詞上的一次具體困難，例如準備起音、短吸氣失敗、嘴形停住、重新啟動或放棄。選符合該場目的的一項，安排與發音相容的口部動作；吞嚥、抿唇等放在空隙。避免把整句機械重複當作所有痛苦的公式，也不把現實中的口吃當作特定情緒的診斷。[Y2](sources.md#y2-對話停頓與搶話)

可同時設計「洩漏、自我控制、關注對象」：例如手指收緊暴露壓力、語速放慢維持表面控制、仍留意對方是否離開。關注對象讓微動作服務關係，而非堆疊眼紅、落淚與顫抖。

### 原創對話草案

C1 想阻止 C2 離開，卻不願承認自己害怕。C2 說「你已經同意了」；C1 在「同意」後想插入「我……」，嘴唇準備起音卻只短暫吸氣，視線仍追著 C2，頭和肩保持。C2 的尾音繼續，C1 等到空隙才把「我沒有」說完；尾音後下顎稍鬆，握住椅背的手仍未放開。這是導演草案，聲音重疊、嘴型與時長待音軌和模型驗證。

### 瞳 MV 的適配

歌曲已鎖定時保留原詞、音節、唱法、節奏與主音軌。需要「不願回答」可讓目光停住、手指中斷、唱完後笑意退去，或切不唱歌的聽者反應；不能自行加字、改成結巴、截斷唱詞或生成新的主唱。未提供音軌時標記歌詞事件，例如「請微笑」尾音後，精確秒數待綁定。已錄好的歌曲若有戲劇停頓，表演依其實際長度設計。

## 驗收與局部修正

分別記錄「通過／需修正／未檢查」，附 take、音軌版本和時間點。

- 視覺：刺激是否先於反應；主要局部改變是否可讀；保持條件及聽者反應是否延續。
- 聲音：實際聽審重疊、截斷位置、可懂度、呼吸和主音軌是否被改動。ASR與波形僅供定位。
- 接鏡：濕痕、眼線、張力、持物、話語權與未完成動作是否接上；不在反打重新哭或重新起整個反應。
- 能力：文字或看圖檢查不算影片生成驗收；抽幀不證明完整動態順序。聲音未聽就保留未檢查。

只修出錯層。局部重做時記錄「已接受的起始狀態 → 需要改正的事件 → 接回原片的終態」，保護已成立區間。[Y3](sources.md#y3-多人站位與控場) 的片段重拍是平台功能示例；本機沒有該功能時改用可用的拆鏡、重做該 take 或剪輯方案，不假定任意影片都能局部無縫修復。
