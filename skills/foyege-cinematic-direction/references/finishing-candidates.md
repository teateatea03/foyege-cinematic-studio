# 後製、恢復與動態圖形：第二輪選用卡

2026-11-09。用於評估小臉修復、超分、階段恢復、MV 字卡或新增聲音工具。這是原創選用方法；候選未因此成為已部署功能。先保護 Foyege 的眼神、微表情、克制停頓與接鏡，再處理清晰度。完整來源與調查界線見 [第二輪研究](https://github.com/teateatea03/foyege-cinematic-studio/blob/main/docs/RESEARCH_2026-11-09-t8-remaining.md)。

三項方法已有原創腳本、原生節點接線契約及短測入口，實際執行讀 [後製實作](finishing-tools.md)。檔案／像素核對與字卡已測，H3 真實冷恢復、修臉及微表情仍依各鏡驗收。

## 優先採用的方法

### 1. 保存完成階段，從接受的 take 續做

適合長鏡重試、局部返修及已完成採樣後的解碼／交付。先查既有 H3 路線是否能分開保存來源、條件與完成階段，不先建立另一套長片生成系統。

- 保存實際源片與音軌身份、幀率／幀區間、角色／參考、模型／節點版本、當次計畫與完成階段。多人每角分開，不能用人物索引代替穩定角色 ID。
- 恢復時核對必要身份；換來源、參考、時間、條件或採樣方法建立新版本。只改交付或合成遮罩，是否能重用採樣須依當前路線判定。
- 外部 take 續接只使用實際已接受的前段；記錄上下文範圍及裁除量，避免畫面或聲音重複。
- 「零擴散採樣」不等於零模型或零計算：不同冷載入路線仍可能需要 VAE 解碼、來源核對與合成。

最小驗證：同一短 take 完成一次保存，再以新程序恢復；按該交付路線比較完整 RGB／PCM、幀數、時長與原音軌，查看接點和完整續段。必要來源錯配應拒絕重用。技術恢復通過與成片接受分開記錄。

### 2. 保護原表演，再評估局部修臉

H3 FaceRefine 會追蹤、裁切並重新生成臉，不是找回原來必然存在的細節。更清楚的眼睛若改掉視線或反應時序，仍算失敗。先保留原片，以同源、同幀、同幾何的可見臉遮罩限制候選影響；遮罩不是頭姿校正器。

- 固定機位可先評估手動畫 ROI，移動人物仍需逐幀可靠區域；已有 SAM3D 或不明 YOLO 權重不代表具備臉部追蹤／遮擋分割。
- 逐鏡選角色；遮擋、轉頭或追蹤遺失時保留原像素並回報區間，不能轉而抓最近的另一張臉。硬切後重建角色對應；無切鏡偵測時先人工拆鏡。
- 檢查眼睛先動／頭後動、眨眼、嘴角、呼吸、嘴型、克制保持的起止時間。不能只比較單張臉部清晰度。
- 來源 B、已混合完成的候選 C、可見遮罩 V，外置保護使用 B + (C − B) × V；C 已含原混合強度，不能再乘一次原 alpha。V 為零處應保留來源；全流程有損重編碼可能另改像素，需區分合成與交付測量。

最小驗證：自有短片包含「看向門、壓下嘴角、保持」，加一段手遮臉或第二人入鏡。比較原片／候選／遮罩合成，原速連看並放大逐幀查變化區；追蹤遺失和遮擋須可回退。沒有原表演可比較時，只能列修復候選，不能宣稱保留微表情。

### 3. 可重現的 MV 字卡與連續運動檢查

適合瞳的系統啟動、ERROR、權限不足與片尾介面。先用既有剪輯、Blender 或可用程式圖形工具；借鑑 Code-Animate 的方法，不複製其未知授權技能或模板。

- 把時間、字體、素材、亂數種子與主音軌版本明列，使用自有資產。相同環境與時間點可重現，逐鏡輸出方便返修。
- 純時間函數可跳到指定時間檢查；有狀態的粒子／物理模擬須從固定初態順序重播，或檢查已渲染影片。
- 查連續幀和整段原速運動，再查文字、聲音觸發和接鏡。低幀差不能直接判為壞片：克制表演、定格、故障閃爍及刻意震屏需對照導演意圖。
- 抽幀和運動數值無法證明完整運動／台詞品質；ASR 只輔助查漏句、重複與串音，最終仍須看聽。

最小驗證：以自有素材做一段含停頓、快速字形／細線運動及 ERROR 觸發的短片。相同設定重渲染、核對時間點及字形，連續觀看；故意定格應保留，非預期卡頓列返修。

## 按製作缺口保留的候選

| 候選 | 值得保留的用途 | 啟用前必要界線 |
|---|---|---|
| FireRedAudio | 對白 ASR 回讀、局部重錄回填、等長角色分軌 | 先比較既有配音／剪輯能否完成；獨立 worker 和模型另備，未本機實測；ASR 分數不能評定情感表演 |
| IndexTTS 2.5 | 逐句情緒與試音備案 | 固定 revision 的依賴要求 Transformers >=4.52.1,<5，與現有 host 5.x 不同；隔離驗證，不能直接裝入主環境或取代專案聲線 |
| VOSR2 | 已接受的劇照／關鍵幀超分 | IMAGE batch 不等於時序修復；約 7GB 配套首次執行自動下載，匹配 VAE／編碼器不可隨意替換；影片須另驗閃爍、眼神與身份 |
| Hi3D | 具體道具精修、分件或既有 rig 的動作重定向 | 先用 Blender／SAM3D；不等於可控制微表情的臉部 rig |
| Meridian | 既有片段的小幅重運鏡 | 先用 Blender 預演；專屬權重、幾何、顯存及各項用途條款另核對 |
| Semantic Bridge | 特定動作遵循研發 | 先修導演卡／參考責任；同條件 held-out 場景比較，保護表演及無關動作 |

Topaz／DLSS 待交付確有超分需求、runtime 與授權就緒再評估；驅動版本達數字門檻不代表功能可用。不為候選更新驅動或停用另一張卡。RFMSR／SeedVR／FlashVSR 的這次影片線索未唯一對應實作，先補來源。新音樂／換聲工具、換角工廠與影片轉技能模板目前重疊較多；「無版權演員庫」未取得素材權利證據，不列可用資產。

候選篩選當時只有文件、依賴與有限本機目錄比對；沒有新安裝、模型下載、服務啟動、GPU 推論或完整教學觀看。後續原創工具短測另見後製實作，來源中的測試仍不冒稱本機結果。
